## October 2026

#### 03 October 2026 — Colors

- Added the NepUI color system with a complete palette of color variables and utility classes.
- Colors can be used in any project by importing the standalone `colors.css` stylesheet.
- Added support for CSS variables and utility classes such as `bg-*`, `text-*`, and `border-*`.
- Added documentation for setup and usage.

[Read more](/docs/colors)
