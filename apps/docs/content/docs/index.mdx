---
title: Installation
description: Install nepui components in HTML, React, and Next.js projects.
---

nepui components are added as source files to your project, so you can use and
customize only what you need. HTML components use standard HTML, CSS, and
JavaScript; React components are provided as TSX and CSS. nepui does not require
Tailwind CSS or a separate runtime component package.

Use the [CLI](/docs/cli) to initialize your project and add components. It
requires Node.js 18 or later and runs on demand with `npx`.

## HTML

HTML components work in any HTML project and do not require a JavaScript
framework or a build step.

### 1. Initialize nepui

From your project directory, create the base token stylesheet:

```bash
npx nepui@latest init . --target html
```

This writes `styles/tokens.css`.

### 2. Add a component

```bash
npx nepui@latest add button --target html
```

The CLI adds the component markup under `html/` and its styles under
`styles/`. For example, the button files are `html/button.html` and
`styles/button.css`. Copy the markup into your page.

### 3. Include the styles

Link the token and component stylesheets from your HTML:

```html
<link rel="stylesheet" href="/styles/tokens.css" />
<link rel="stylesheet" href="/styles/button.css" />
```

Some components also include JavaScript. If the component has a JavaScript
file, load it from the `html/` directory as described on that component's
documentation page.

## React

The CLI adds React component source to your project. Start with an existing
React app; for example:

```bash
npm create vite@latest my-app -- --template react-ts
cd my-app
npm install
```

### 1. Initialize nepui

From the React project directory, run:

```bash
npx nepui@latest init . --target react
```

This writes `components/nepui/tokens.css` and installs `@base-ui/react`, `class-variance-authority`, and `cn` as dependencies. The `tokens.css` file contains the base design tokens for your project.

### 2. Add a component

```bash
npx nepui@latest add button --target react
```

Component files are added under `components/nepui/`. Import and use the
component:

```tsx
import { Button } from "@/components/nepui/button"

export function Example() {
  return <Button>Continue</Button>
}
```

Configure the `@/` import alias for your project, or update the import path to
match your setup.

### 3. Include the styles

Import the tokens from your app's global CSS file:

```css title="globals.css"
@import "../components/nepui/tokens.css";
```

Adjust the relative paths to match where your global stylesheet is located.

## Next.js

nepui works with both the App Router and Pages Router. Initialize and add React
components using the steps above. Import the global stylesheet from your root
layout (App Router) or `_app.tsx` (Pages Router).

For example, with the App Router:

```tsx
import "./globals.css"

export default function RootLayout({
  children,
}: Readonly<{ children: React.ReactNode }>) {
  return (
    <html lang="en">
      <body>{children}</body>
    </html>
  )
}
```

Components that use client-side interaction include the `"use client"`
directive where needed. If you use them in your own component, follow the
standard Next.js Client Component rules.

## Add more components

Add multiple named components in one command:

```bash
npx nepui@latest add button card spinner --target react
```

To see available components for a target:

```bash
npx nepui@latest list --target html
npx nepui@latest list --target react
```

Browse the [components](/docs/components) or See the
[CLI guide](/docs/cli) for all commands and options.
