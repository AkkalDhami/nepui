## Usage

Link the stylesheet, after `tokens.css`. There is no script.

```html 
<link rel="stylesheet" href="./styles/aurora.css">
```

```html 
<section class="np-aurora" data-gradient="ocean">
  <h1>Interfaces that feel alive</h1>
</section>
```

The glow sits behind the content, so children need no extra styling. The box clips the glow, so give it a size, such as padding or a height. The glow blends with `--np-background`, so it works in light and dark.

## Gradients

Set `data-gradient` to a name. The names are `aurora`, `sunrise`, `sunset`, `ocean`, `forest`, `fire`, `candy`, `lavender`, `mint`, `peach`, `midnight`, `gold`, `rainbow`, `cyber`, `plasma`, `mono`. Without one, the glow uses `aurora`. The names match the ones in Gradient Text.

## Intensity, speed and stillness

Use `data-intensity` (`subtle` or `strong`), `data-speed` (`slow` or `fast`) and `data-animate="false"`.

## Your own gradient

Add a rule to your own stylesheet that sets the five stops for a name of your choice, then use that name.

```css
[data-gradient="brand"] {
  --np-aurora-color-1: oklch(0.7 0.2 20);
  --np-aurora-color-2: oklch(0.75 0.18 50);
  --np-aurora-color-3: oklch(0.8 0.16 90);
  --np-aurora-color-4: oklch(0.75 0.18 50);
  --np-aurora-color-5: oklch(0.7 0.2 20);
}
```

## Reference

| Class | Attribute | Description |
| --- | --- | --- |
| `np-aurora` | `data-np-aurora` | The box that holds the content and the glow. |

| Attribute | Values | Default |
| --- | --- | --- |
| `data-gradient` | `"aurora" \| "sunrise" \| "sunset" \| "ocean" \| "forest" \| "fire" \| "candy" \| "lavender" \| "mint" \| "peach" \| "midnight" \| "gold" \| "rainbow" \| "cyber" \| "plasma" \| "mono"`| `aurora` |
| `data-mask` | `"corner" \| "center" \| "top" \| "bottom" \| "none"` | `"corner"` |
| `data-intensity` | `"subtle" \| "strong"` | `0.6` opacity |
| `data-speed` | `"slow" \| "fast"` | A `60s` loop |
| `data-animate` | `false` | Animated |
