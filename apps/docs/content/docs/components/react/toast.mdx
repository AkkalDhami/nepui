## Usage

```tsx
import { toast } from "@/components/nepui/toast"
```

```tsx
toast.add({
  title: "Event created",
  description: "Sunday, December 3 at 9:00 AM",
})
```

Toasts stack at the top center of the screen. Hover or focus the stack to spread it out, which also pauses the timers. Swipe a toast up, left or right to dismiss it.

```tsx
const id = toast.add({
  title: "Event created",
  actionProps: {
    children: "Undo",
    onClick() {
      toast.close(id)
    },
  },
})
```

## Styling

Set these variables on the toast (for example with `className` on `Toast`, or in your own CSS).

| Variable | Default | Description |
| -------- | ------- | ----------- |
| `--np-toast-gap` | `0.75rem` | Space between toasts when the stack is expanded. |
| `--np-toast-peek` | `0.75rem` | How much each stacked toast peeks out below the one in front. |
| `--np-toast-scale-step` | `0.1` | How much smaller each stacked toast gets. |
| `--np-toast-radius` | `var(--np-radius-full)` | Corner radius. Use `var(--np-radius-lg)` for a card. |
| `--np-toast-bg` | `var(--np-popover)` | Background color. |
| `--np-toast-color` | `var(--np-popover-foreground)` | Text color. |
| `--np-toast-border` | `var(--np-border)` | Border color. |
| `--np-toast-shadow` | `var(--np-shadow-lg)` | Drop shadow. |
| `--np-toast-duration` | `500ms` | Length of the move and stack animation. |
| `--np-toast-icon-size` | `1.25rem` | Status icon size. |
| `--np-toast-info-color` | `var(--np-info, oklch(0.546 0.245 262.881))` | Icon color of the info type. |

## API Reference

This component wraps the [Base UI Toast](https://base-ui.com/react/components/toast). See its documentation for manager options, stacking, swipe dismissal and the primitive API. The animation that the source of this component did with a motion library is plain CSS here, so there is no extra dependency.

### toast

The shared toast manager.

| Method | Description |
| ------ | ----------- |
| `toast.add(options)` | Shows a toast and returns its id. Options include `title`, `description`, `type`, `timeout` and `actionProps`. |
| `toast.update(id, options)` | Changes a toast that is showing. |
| `toast.close(id)` | Closes a toast. |
| `toast.promise(promise, messages)` | Shows a loading toast and turns it into a success or error toast. |

### Toaster

Provides the manager and renders every toast. It accepts all Base UI `Toast.Provider` props, such as `limit` and `timeout`.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `toastManager` | `ToastManager` | `toast` |
| `limit` | `number` | `3` |
| `timeout` | `number` | `5000` |

### Toast parts

`Toast`, `ToastContent`, `ToastTitle`, `ToastDescription`, `ToastAction`, `ToastClose`, `ToastViewport`, `ToastPortal` and `ToastProvider` are exported for custom layouts. `Toast` accepts `swipeDirection` (default `["up", "left", "right"]`). `ToastAction` and `ToastClose` render nepui Buttons and accept a `render` prop to change that.
