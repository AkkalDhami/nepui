## Usage

```tsx
import { DatePicker } from "@/components/nepui/date-picker"
```

```tsx
<DatePicker />
```

Use `value` and `onValueChange` to control it, or `defaultValue` to start with a date. The panel closes after a date is picked, and the date is formatted with `Intl.DateTimeFormat`, so pass `locale` and `formatOptions` to change it.

```tsx
const [date, setDate] = React.useState<Date | undefined>()

<DatePicker value={date} onValueChange={setDate} />
```

See the [React DayPicker](https://react-day-picker.js.org) documentation for the calendar options you can pass through `calendarProps`.

## Composition

`DatePicker` is a composition of the Popover and the Calendar. You can build your own the same way:

```text
Popover
├── PopoverTrigger
└── PopoverContent
    └── Calendar
```

Give the content the `np-date-picker-content` class so the panel fits the calendar. The trigger uses the `np-date-picker-trigger` class and `data-empty` to dim the placeholder.

## API Reference

### DatePicker

| Prop | Type | Default |
| ---- | ---- | ------- |
| `value` | `Date \| undefined` | - |
| `defaultValue` | `Date` | - |
| `onValueChange` | `(date: Date \| undefined) => void` | - |
| `placeholder` | `string` | `"Pick a date"` |
| `locale` | `string` | browser default |
| `formatOptions` | `Intl.DateTimeFormatOptions` | `{ dateStyle: "long" }` |
| `align` | `"start" \| "center" \| "end"` | `"start"` |
| `calendarProps` | calendar options | - |
| `disabled` | `boolean` | `false` |
| `id` | `string` | - |
| `name` | `string` | - |
| `className` | `string` | - |

### DateRangePicker

The same props, with a `DateRange` (`{ from, to }`) as the value, `"Pick a date range"` as the placeholder and `{ dateStyle: "medium" }` as the format. It shows two months.
