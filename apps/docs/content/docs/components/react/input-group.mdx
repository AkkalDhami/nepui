## Usage

```tsx
import {
  InputGroup,
  InputGroupAddon,
  InputGroupButton,
  InputGroupInput,
  InputGroupText,
  InputGroupTextarea,
} from "@/components/nepui/input-group"
```

```tsx
<InputGroup>
  <InputGroupInput placeholder="Search..." />
  <InputGroupAddon>
    <SearchIcon />
  </InputGroupAddon>
</InputGroup>
```

---

## Composition

Use the following composition to build an `InputGroup`:

```text
InputGroup
├── InputGroupInput or InputGroupTextarea
├── InputGroupAddon
├── InputGroupButton
└── InputGroupText
```

---

## Align

Use the `align` prop on `InputGroupAddon` to place it before or after the control, or above or below it.
 
| Value          | Position                                      |
| -------------- | --------------------------------------------- |
| `inline-start` | Before the control (default)                  |
| `inline-end`   | After the control                             |
| `block-start`  | Above the control, on its own row             |
| `block-end`    | Below the control, on its own row             |
 
Addons can be written in any order in your JSX. Their position follows `align`, not the source order.

## API Reference
 
### InputGroup
 
The main component that wraps the control and its addons.
 
| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | —       |
 
### InputGroupAddon
 
Displays icons, text, buttons or shortcuts before, after, above or below the control.
 
| Prop        | Type                                                             | Default          |
| ----------- | ---------------------------------------------------------------- | ---------------- |
| `align`     | `"inline-start" \| "inline-end" \| "block-start" \| "block-end"` | `"inline-start"` |
| `className` | `string`                                                         | —                |
 
### InputGroupButton
 
A button inside an addon. It accepts the props of [Button](/docs/components/react/button), except `size`.
 
| Prop        | Type                                                  | Default   |
| ----------- | ----------------------------------------------------- | --------- |
| `size`      | `"xs" \| "sm" \| "icon-xs" \| "icon-sm"`              | `"xs"`    |
| `variant`   | Any [Button](/docs/components/react/button) variant   | `"ghost"` |
| `type`      | `"button" \| "submit" \| "reset"`                      | `"button"` |
| `className` | `string`                                              | —         |
 
### InputGroupInput
 
The input of the group. It accepts the props of [Input](/docs/components/react/input).
 
| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | —       |
 
### InputGroupTextarea
 
The textarea of the group. It accepts the props of [Textarea](/docs/components/react/textarea).
 
| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | —       |
 
### InputGroupText
 
Static text, a prefix, a suffix or a unit inside an addon.
 
| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | —       |
