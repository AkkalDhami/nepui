## Usage

```tsx
import { Calendar } from "@/components/nepui/calendar"
```

```tsx
const [date, setDate] = React.useState<Date | undefined>(new Date())

return (
  <Calendar mode="single" selected={date} onSelect={setDate} bordered />
)
```

See the [React DayPicker documentation](https://daypicker.dev) for more information.

---

## About

The Calendar component is built on top of [React DayPicker](https://daypicker.dev).

## Persian, Hijri and Jalali calendars

To use the Persian calendar, edit `calendar.tsx` and import `DayPicker` from `react-day-picker/persian` instead of `react-day-picker`.

---

## Time zones

Pass a `timeZone` prop so dates are shown and selected in the visitor's time zone. Detect it in an effect to avoid a hydration mismatch.

```tsx
const [timeZone, setTimeZone] = React.useState<string | undefined>()

React.useEffect(() => {
  setTimeZone(Intl.DateTimeFormat().resolvedOptions().timeZone)
}, [])

<Calendar mode="single" selected={date} onSelect={setDate} timeZone={timeZone} />
```

## API Reference

See the [React DayPicker documentation](https://daypicker.dev) for the full list of props.

### Calendar

| Prop | Type | Default |
| ---- | ---- | ------- |
| `mode` | `"single" \| "multiple" \| "range"` | - |
| `selected` | `Date \| Date[] \| DateRange` | - |
| `onSelect` | `(selected) => void` | - |
| `numberOfMonths` | `number` | `1` |
| `captionLayout` | `"label" \| "dropdown" \| "dropdown-months" \| "dropdown-years"` | `"label"` |
| `showOutsideDays` | `boolean` | `true` |
| `showWeekNumber` | `boolean` | `false` |
| `locale` | `Locale` | - |
| `dir` | `"ltr" \| "rtl"` | - |
| `bordered` | `boolean` | `false` |
| `className` | `string` | - |

### CalendarDayButton

The button that renders a day. Use it inside a custom `DayButton` component to add content to a cell.
