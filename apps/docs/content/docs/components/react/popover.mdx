## Usage

```tsx
import {
  Popover,
  PopoverContent,
  PopoverDescription,
  PopoverHeader,
  PopoverTitle,
  PopoverTrigger,
} from "@/components/nepui/popover"
```

```tsx
<Popover>
  <PopoverTrigger render={<Button variant="outline" />}>
    Open Popover
  </PopoverTrigger>
  <PopoverContent>
    <PopoverHeader>
      <PopoverTitle>Title</PopoverTitle>
      <PopoverDescription>Description text here.</PopoverDescription>
    </PopoverHeader>
  </PopoverContent>
</Popover>
```

---

## Composition

Use the following composition to build a `Popover`:

```text
Popover
├── PopoverTrigger
└── PopoverContent
    ├── PopoverHeader
    │   ├── PopoverTitle
    │   └── PopoverDescription
    └── PopoverClose
```

## Side

Use the `side` prop on `PopoverContent` to choose `top`, `right`, `bottom` or `left`. The popover flips to the other side when there is no room, and `sideOffset` and `alignOffset` fine-tune the distance in pixels.

## API Reference

This component wraps the [Base UI Popover](https://base-ui.com/react/components/popover). Each part accepts all props of the matching Base UI part, including hover opening (`openOnHover` on the trigger), detached triggers (`handle`) and `modal` on the root.

### Popover

Groups all parts. It renders no element of its own.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `open` | `boolean` | - |
| `defaultOpen` | `boolean` | `false` |
| `onOpenChange` | `(open: boolean, eventDetails) => void` | - |
| `modal` | `boolean \| "trap-focus"` | `false` |

### PopoverTrigger

A button that opens the popover.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `render` | `ReactElement \| (props, state) => ReactElement` | - |
| `openOnHover` | `boolean` | `false` |
| `delay` | `number` | `300` |
| `className` | `string \| (state) => string` | - |

### PopoverContent

The popover panel, rendered in a portal.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `side` | `"top" \| "right" \| "bottom" \| "left" \| "inline-start" \| "inline-end"` | `"bottom"` |
| `align` | `"start" \| "center" \| "end"` | `"center"` |
| `sideOffset` | `number` | `4` |
| `alignOffset` | `number` | `0` |
| `className` | `string \| (state) => string` | - |

### PopoverHeader

Groups the title and description. Renders a `div`.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `className` | `string` | - |

### PopoverTitle

A heading that labels the popover. Renders an `h2`.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `className` | `string \| (state) => string` | - |

### PopoverDescription

Extra information about the popover. Renders a `p`.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `className` | `string \| (state) => string` | - |

### PopoverClose

A button that closes the popover.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `render` | `ReactElement \| (props, state) => ReactElement` | - |
| `className` | `string \| (state) => string` | - |
