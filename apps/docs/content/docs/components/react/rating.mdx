## Usage

```tsx
import { Rating, RatingItem } from "@/components/nepui/rating"
```

```tsx
<Rating aria-label="Rating" defaultValue={3}>
  <RatingItem />
</Rating>
```

Give the rating an accessible name with `aria-label` or `aria-labelledby`. Without `defaultValue`, no star starts checked and Tab enters on the first star.

Each star is a radio, so the rating is a radio group with one value and one tab stop. Arrow keys move the score and check it. Space checks the focused star, and Enter submits the containing form. The icons are hidden from assistive technology, because every radio already has a name.

---

## Composition

```text
Rating
└── RatingItem
```

`Rating` renders its children once for every star, so place one `RatingItem` inside it. With no children it renders a default star.

## Controller

Create one controller for each rating with `createRatingController()` and pass it as `controller`.

| Method | Description |
| --- | --- |
| `getValue()` | Returns the score, or `null`. |
| `setValue(value, details?)` | Sets the score as a user would. Returns `false` if the change is canceled. Ignored when disabled or read-only. |
| `focus()` | Moves focus to the checked star, or to the first star. |

---

## Events

`onValueChange(value, details)` is called when a user, a form reset or the controller asks for a change. `details.reason` is the cause, and `details.cancel()` stops the change.

| Reason | When |
| --- | --- |
| `item-press` | A star was chosen with the pointer or the keyboard. |
| `list-navigation` | The arrow, Home or End keys moved the score. |
| `reset` | A form reset. |
| `imperative` | A controller call changed the score. |

---

## Keyboard

| Key | Behavior |
| --- | --- |
| Tab | Enters the rating on the checked star, or the first star. |
| Arrow keys | Move to the next or previous score and check it. They stop at the ends unless `loop` is set. In RTL, Left and Right swap. |
| Home, End | Go to the lowest score or to `max`. |
| Space | Checks the focused star. Clears it if it is checked and `deselectable` is set. |
| Enter | Submits the containing form. |

## API Reference

### Rating

Renders a `div` with `role="radiogroup"`, or `role="img"` when read-only.

| Prop | Type | Default |
| --- | --- | --- |
| `value` | `number \| null` | |
| `defaultValue` | `number \| null` | `null` |
| `onValueChange` | `(value, details) => void` | |
| `max` | `number` | `5` |
| `step` | `number` | `1` |
| `deselectable` | `boolean` | `false` |
| `disabled` | `boolean` | `false` |
| `readOnly` | `boolean` | `false` |
| `required` | `boolean` | `false` |
| `name` | `string` | |
| `form` | `string` | |
| `loop` | `boolean` | `false` |
| `getValueLabel` | `(value, max) => string` | `"3 out of 5 stars"` |
| `controller` | `RatingController` | |
| `size` | `"default" \| "sm" \| "lg"` | `"default"` |
| `debug` | `boolean` | `false` |

### RatingItem

Renders a `button` with `role="radio"`, or a `span` when the rating is read-only. The children can be an icon or a function that gets the star's state.

| State | Type | Description |
| --- | --- | --- |
| `value` | `number \| null` | The current score. |
| `preview` | `number \| null` | The score previewed under the pointer. |
| `index` | `number` | The position of the star, starting at 1. |
| `fill` | `number` | How much of the star the shown score covers, from 0 to 1. |
| `checked` | `boolean` | Whether the score ends in this star. |
| `highlighted` | `boolean` | Whether a previewed score reaches this star. |
| `disabled`, `readOnly`, `required` | `boolean` | The state of the rating. |
