## Usage

```tsx
import { ScrollArea, ScrollBar } from "@/components/nepui/scroll-area"
```

```tsx
<ScrollArea style={{ height: 288, width: 192 }}>
  {/* Long content */}
</ScrollArea>
```

Give the scroll area a fixed size (`height`, `width` or `max-height`). Without one, the content simply grows and nothing scrolls.

## API Reference

This component wraps the [Base UI Scroll Area](https://base-ui.com/react/components/scroll-area). It accepts every prop of the matching Base UI part.

### ScrollArea

The root. It renders the viewport, a vertical `ScrollBar` and the corner for you.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `fade` | `boolean` | `false` |
| `overflowEdgeThreshold` | `number \| Partial<{ xStart: number; xEnd: number; yStart: number; yEnd: number }>` | `0` |

### ScrollBar

A scrollbar track with its thumb. It only shows while the content overflows on its axis.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `orientation` | `"vertical" \| "horizontal"` | `"vertical"` |
| `keepMounted` | `boolean` | `false` |
