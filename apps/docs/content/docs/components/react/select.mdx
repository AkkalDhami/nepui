## Usage

```tsx
import {
  Select,
  SelectContent,
  SelectGroup,
  SelectItem,
  SelectTrigger,
  SelectValue,
} from "@/components/nepui/select"
```


```tsx showLineNumbers
const items = [
  { label: "Light", value: "light" },
  { label: "Dark", value: "dark" },
  { label: "System", value: "system" },
]

<Select items={items}>
  <SelectTrigger style={{ width: "12rem" }}>
    <SelectValue placeholder="Theme" />
  </SelectTrigger>
  <SelectContent>
    <SelectGroup>
      {items.map((item) => (
        <SelectItem key={item.value} value={item.value}>
          {item.label}
        </SelectItem>
      ))}
    </SelectGroup>
  </SelectContent>
</Select>
```

Pass `items` to `Select` so `SelectValue` can show an item's label instead of its raw value.

## Composition

Use the following composition to build a `Select`:

```text
Select
├── SelectTrigger
│   └── SelectValue
└── SelectContent
    ├── SelectGroup
    │   ├── SelectLabel
    │   ├── SelectItem
    │   └── SelectItem
    ├── SelectSeparator
    └── SelectGroup
        ├── SelectLabel
        ├── SelectItem
        └── SelectItem
```

  <FieldLabel>Fruit</FieldLabel>
  <SelectTrigger aria-invalid>
    <SelectValue />

## Native

Set `native` on `Select` to render a native `<select>` instead of the Base UI popup. Use it when you want the platform picker, for example on mobile, or when you need no popup JavaScript.

In native mode `Select` takes the props of a `<select>` plus `size`, `placeholder` and `wrapperClassName`. Use `SelectOption` and `SelectOptGroup` as children.

`SelectTrigger`, `SelectValue`, `SelectContent`, `SelectItem`, `SelectLabel` and `SelectSeparator` are only for the Base UI popup.

<ComponentPreview
  name="select-native"
/>

`placeholder` adds a leading empty, disabled option. When the select is uncontrolled and has no `defaultValue`, it starts on that option. Native `multiple` is not supported.

```tsx
<Select native aria-label="Fruit" placeholder="Select a fruit" style={{ width: "12rem" }}>
  <SelectOption value="apple">Apple</SelectOption>
  <SelectOption value="banana">Banana</SelectOption>
</Select>
```

## API Reference

### Select

| Prop | Type | Default |
| ---- | ---- | ------- |
| `native` | `boolean` | `false` |
| `size` | `"xs" \| "sm" \| "default" \| "lg"` (native only) | `"default"` |
| `placeholder` | `string` (native only) | - |
| `wrapperClassName` | `string` (native only) | - |

Without `native`, `Select` is the Base UI [Select root](https://base-ui.com/react/components/select).

With `native`, it accepts the props of a `<select>` except `size` and `multiple`; `className` is applied to the `<select>`.

### SelectTrigger

| Prop | Type | Default |
| ---- | ---- | ------- |
| `size` | `"xs" \| "sm" \| "default" \| "lg"` | `"default"` |

### SelectValue

| Prop | Type | Default |
| ---- | ---- | ------- |
| `placeholder` | `ReactNode` | - |

### SelectContent

| Prop | Type | Default |
| ---- | ---- | ------- |
| `side` | `"top" \| "bottom" \| "left" \| "right" \| "inline-start" \| "inline-end"` | `"bottom"` |
| `sideOffset` | `number` | `4` |
| `align` | `"start" \| "center" \| "end"` | `"center"` |
| `alignOffset` | `number` | `0` |
| `alignItemWithTrigger` | `boolean` | `true` |

### SelectItem

| Prop | Type | Default |
| ---- | ---- | ------- |
| `value` | `any` | - |
| `disabled` | `boolean` | `false` |
