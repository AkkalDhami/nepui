## Usage

```tsx
import {
  Group,
  GroupSeparator,
  GroupText,
} from "@/components/nepui/group"
```

```tsx
<Group aria-label="File actions">
  <Button variant="outline">Files</Button>
  <GroupSeparator />
  <Button variant="outline">Media</Button>
</Group>
```

The children of the group are the controls. Their inner corners and the border between them are removed. A control should draw its own border and radius, as the nepui `Button`, `Input` and `Select` do. A control followed by a `GroupSeparator` drops its end border, so the divider is not doubled. Without a separator, the neighbours share one border.

Give the group a name with `aria-label` or `aria-labelledby`. Use a group for controls that do something. For controls that toggle, use a toggle group. Colours come from tokens, so dark mode needs no extra setup. The styles use `:has()` and `color-mix()`, which need a modern browser.

`ButtonGroup`, `ButtonGroupText` and `ButtonGroupSeparator` are exported as aliases.

## Accessibility

- The group has `role="group"`. Name it with `aria-label` or `aria-labelledby`.
- Tab moves between the controls, in order.
- The separator is decoration. It takes no focus.

## API Reference

### Group

Renders a `div` with `role="group"`.

| Prop | Type | Default |
| --- | --- | --- |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` |
| `className` | `string` | - |

### GroupSeparator

Renders a `div` with `role="separator"`.

| Prop | Type | Default |
| --- | --- | --- |
| `orientation` | `"horizontal" \| "vertical"` (the direction of the line) | `"vertical"` |
| `className` | `string` | - |

### GroupText

Renders a `div`.

| Prop | Type | Default |
| --- | --- | --- |
| `render` | `ReactElement \| (props, state) => ReactElement` | - |
| `className` | `string` | - |
