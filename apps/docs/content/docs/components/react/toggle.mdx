## Usage

```tsx
import { Toggle } from "@/components/nepui/toggle"
```

```tsx
<Toggle aria-label="Toggle bold">Bold</Toggle>
```

Icon-only toggles have no visible text, so always give them an `aria-label`.

## Filled Icon

The toggle is uncontrolled by default. Pass `pressed` and `onPressedChange` to control it, for example to swap the icon weight while the toggle is on.

This demo uses Phosphor's `weight` prop. For stroke-based icon sets such as Lucide, set `fillIcon` instead and the CSS fills the icon with `currentColor` while the toggle is pressed.

## API Reference

### Toggle

Built on the [Base UI Toggle](https://base-ui.com/react/components/toggle#api-reference). All Base UI props are supported.

| Prop              | Type                                                                          | Default     |
| ----------------- | ----------------------------------------------------------------------------- | ----------- |
| `variant`         | `"default" \| "outline"`                                                      | `"default"` |
| `size`            | `"default" \| "sm" \| "lg"`                                                   | `"default"` |
| `fillIcon`        | `boolean`                                                                     | `false`     |
| `pressed`         | `boolean`                                                                     | -           |
| `defaultPressed`  | `boolean`                                                                     | `false`     |
| `onPressedChange` | `(pressed: boolean, eventDetails: Toggle.ChangeEventDetails) => void`         | -           |
| `value`           | `string`                                                                      | -           |
| `disabled`        | `boolean`                                                                     | `false`     |
| `render`          | `ReactElement \| function`                                                    | -           |
| `className`       | `string \| (state) => string`                                                 | -           |
