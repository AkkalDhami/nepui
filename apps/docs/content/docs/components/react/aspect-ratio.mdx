## Usage

```tsx
import { AspectRatio } from "@/components/nepui/aspect-ratio"
```

```tsx
<AspectRatio ratio={16 / 9}>
  <img src="..." alt="Image" style={{ borderRadius: "var(--np-radius-md)" }} />
</AspectRatio>
```

An `img`, `video` or `iframe` that is a direct child fills the box and is cropped with `object-fit: cover`. Set `--np-aspect-ratio-fit: contain` on the component to show the whole image instead. Give any other child `height: 100%` if it should fill the box too.

## API Reference

### AspectRatio

The `AspectRatio` component displays content within a desired ratio. It renders a `div` and accepts every `div` prop.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `ratio` | `number` | - |
| `className` | `string` | - |
