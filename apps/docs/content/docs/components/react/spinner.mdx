## Usage

```tsx
import { Spinner } from "@/components/spinner/spinner"
```

```tsx
<Spinner size="xs" speed="fast" />
<Spinner size="sm" speed="slow" />
<Spinner />
<Spinner size="lg" direction="counter-clockwise" />
<Spinner size="xl" speed="faster" thickness="thick" />
<Spinner size="5rem" speed="200ms" thickness="0.5rem" />
```

---

## Size

Use the `size` prop to change the size of the spinner.

<ComponentPreview
  name="spinner-size"
/>

Available sizes are `xs`, `sm`, `md` (default), `lg`, and `xl`. Custom CSS sizes such as `24px` and `5rem` are also supported.

| Size             | Prop          |
| ---------------- | ------------- |
| Extra small      | `size="xs"`   |
| Small            | `size="sm"`   |
| Medium (default) | `size="md"`   |
| Large            | `size="lg"`   |
| Extra large      | `size="xl"`   |
| Custom           | `size="5rem"` |

---

## Speed

Use the `speed` prop to control the spinner's animation speed.

<ComponentPreview
  name="spinner-speed"
/>

Available speeds are `slow`, `normal` (default), `fast`, and `faster`. Custom durations such as `200ms` and `1s` are also supported.

| Speed            | Prop             |
| ---------------- | ---------------- |
| Slow             | `speed="slow"`   |
| Normal (default) | `speed="normal"` |
| Fast             | `speed="fast"`   |
| Faster           | `speed="faster"` |
| Custom           | `speed="200ms"`  |

---

## Thickness

Use the `thickness` prop to control the spinner's border thickness.

<ComponentPreview
  name="spinner-thickness"
/>

Available thicknesses are `thin`, `normal` (default), `medium`, `thick`, and `extra-thick`.

| Thickness        | Prop                      |
| ---------------- | ------------------------- |
| Thin             | `thickness="thin"`        |
| Normal (default) | `thickness="normal"`      |
| Medium           | `thickness="medium"`      |
| Thick            | `thickness="thick"`       |
| Extra thick      | `thickness="extra-thick"` |
| Custom      | `thickness="3px"` |

---

## Direction

Use the `direction` prop to control the spinner's rotation direction.

<ComponentPreview
  name="spinner-direction"
/>

Available directions are `clockwise` (default) and `counterclockwise`.

| Direction           | Prop                           |
| ------------------- | ------------------------------ |
| Clockwise (default) | `direction="clockwise"`        |
| Counterclockwise    | `direction="counterclockwise"` |

---

## Color

Use the `color` and `mutedColor` prop to customize the spinner's color.

<ComponentPreview
  name="spinner-color"
/>

The `color` prop accepts any valid CSS color value, including named colors, hexadecimal values, and RGB colors. You can also use `mutedColor` to customize the secondary spinner color.

| Color              | Prop                     |
| ------------------ | ------------------------ |
| Named color        | `color="tomato"`         |
| Hex color          | `color="#2563eb"`        |
| RGB color          | `color="rgb(34 197 94)"` |
| Custom muted color | `mutedColor="#0211b7"`   |
