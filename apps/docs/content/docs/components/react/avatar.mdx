## Usage

```tsx
import { Avatar, AvatarFallback, AvatarImage } from "@/components/nepui/avatar"
```

```tsx
<Avatar>
  <AvatarImage src="https://github.com/akkaldhami.png" alt="@akkkaldhami" />
  <AvatarFallback>CN</AvatarFallback>
</Avatar>
```

The fallback shows while the image loads and when it fails to load.

---

## Composition

Use the following composition to build an `Avatar`:

```text
Avatar
├── AvatarImage
├── AvatarFallback
└── AvatarBadge
```

Use the following composition to build an `AvatarGroup`:

```text
AvatarGroup
├── Avatar
│   ├── AvatarImage
│   ├── AvatarFallback
│   └── AvatarBadge
├── Avatar
│   ├── AvatarImage
│   ├── AvatarFallback
│   └── AvatarBadge
└── AvatarGroupCount
```

## API Reference

This component wraps the [Base UI Avatar](https://base-ui.com/react/components/avatar). `Avatar`, `AvatarImage` and `AvatarFallback` accept all props of the matching Base UI part.

### Avatar

The root. It wraps the image and fallback.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `size` | `"default" \| "sm" \| "lg"` | `"default"` |
| `className` | `string \| (state) => string` | - |

### AvatarImage

Displays the avatar image. It only renders once the image has loaded.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `src` | `string` | - |
| `alt` | `string` | - |
| `className` | `string \| (state) => string` | - |

### AvatarFallback

Displayed when the image is loading or fails to load.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `delay` | `number` | - |
| `className` | `string \| (state) => string` | - |

### AvatarBadge

A badge indicator at the bottom end corner of the avatar. Renders a `span`.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `className` | `string` | - |

### AvatarGroup

Displays a group of avatars with overlapping styling. Renders a `div`.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `className` | `string` | - |

### AvatarGroupCount

A count or icon at the end of an avatar group. Renders a `div`.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `className` | `string` | - |
