## Use cases

- Copy buttons that switch to a check on success.
- Toggle buttons such as play and pause.
- Icons that follow the selected tab or option.

## Usage

```tsx
import { IconSwap, IconSwapItem } from "@/components/nepui/icon-swap"
```

```tsx
<IconSwap>
  <IconSwapItem key={isCopied ? "check" : "copy"}>
    {isCopied ? <CheckIcon /> : <CopyIcon />}
  </IconSwapItem>
</IconSwap>
```

Change the `key` on `IconSwapItem` whenever the icon should swap. The old icon stays mounted until its fade-out ends, so both animate at the same time. The icon on first render does not animate.

Put the swap inside a button and give the button an accessible name. The icons are decorative, and the leaving icon is hidden from assistive technology with `aria-hidden`.

---

## Composition

Use the following composition to build an `IconSwap`:

```text
IconSwap
└── IconSwapItem
    └── {icon}
```

## API Reference

### IconSwap

The container. Accepts all `span` props.

| Prop        | Type                                | Default |
| ----------- | ----------------------------------- | ------- |
| `children`  | `ReactElement<IconSwapItemProps>`   | -       |
| `className` | `string`                            | -       |

### IconSwapItem

One icon. Accepts all `span` props. Its `key` decides when the swap happens.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `key`       | `string` | -       |
| `className` | `string` | -       |
