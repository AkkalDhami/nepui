Syntax highlighting is optional. `code-block.tsx` does not import Shiki, so if you never highlight, you can leave out `highlighter.tsx` and `use-highlighted-code.ts` and skip the `shiki` dependency. The language list lives in `highlighter.tsx`.

## Usage

```tsx
import {
  CodeBlock,
  CodeBlockActions,
  CodeBlockContent,
  CodeBlockCopyButton,
  CodeBlockFooter,
  CodeBlockHeader,
  CodeBlockLine,
  CodeBlockTitle,
} from "@/components/nepui/code-block"
```

```tsx
<CodeBlock>
  <CodeBlockHeader>
    <CodeBlockTitle>Terminal</CodeBlockTitle>
    <CodeBlockActions>
      <CodeBlockCopyButton value={output} />
    </CodeBlockActions>
  </CodeBlockHeader>
  <CodeBlockContent>{output}</CodeBlockContent>
</CodeBlock>
```

`CodeBlockContent` takes a string or a list of `CodeBlockLine`. Use lines when you need diff lines, highlighted lines or highlighted tokens. The block works in a Trace, Tabs, a Dialog or a message, since it is a plain `div` that fills its parent.

## Syntax highlighting

`useHighlightedCode(code, language)` returns one node per line, for `CodeBlockLine`. It returns plain lines until the first pass is done, and for a language that is not supported.

Supported by default: `ansi`, `bash`, `css`, `diff`, `html`, `javascript`, `json`, `jsx`, `markdown`, `python`, `sql`, `tsx`, `typescript` and `yaml`, plus aliases such as `js`, `ts`, `sh`, `py`, `md` and `yml`. Use `"ansi"` for terminal colours. To add a language, edit `LANGUAGES` in `highlighter.tsx`.

## Server rendering

`highlightCode` works in a Server Component. It resolves to `null` for a language that is not supported.

```tsx showLineNumbers
import { CodeBlock, CodeBlockContent, CodeBlockLine } from "@/components/nepui/code-block"
import { highlightCode } from "@/lib/highlighter"

export async function ServerCode({ code }: { code: string }) {
  const lines = (await highlightCode(code, "tsx")) ?? code.split("\n")

  return (
    <CodeBlock>
      <CodeBlockContent lineNumbers>
        {lines.map((line, index) => (
          <CodeBlockLine key={index}>{line}</CodeBlockLine>
        ))}
      </CodeBlockContent>
    </CodeBlock>
  )
}
```

## Show more

Cap the height while it is collapsed and put a button in `CodeBlockFooter`.

```tsx showLineNumbers
const [open, setOpen] = React.useState(false)

<CodeBlock>
  <CodeBlockContent
    id="long-code"
    style={open ? undefined : ({ "--np-code-block-max-height": "8rem" } as React.CSSProperties)}
  >
    {code}
  </CodeBlockContent>
  <CodeBlockFooter>
    <Button
      variant="ghost"
      size="xs"
      aria-expanded={open}
      aria-controls="long-code"
      onClick={() => setOpen((value) => !value)}
    >
      {open ? "Show less" : "Show more"}
    </Button>
  </CodeBlockFooter>
</CodeBlock>
```

## API Reference

### CodeBlock

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `"default" \| "destructive"` | `"default"` |
| `size` | `"default" \| "sm"` | `"default"` |
| `className` | `string` | - |

### CodeBlockHeader / CodeBlockTitle / CodeBlockFooter

Render a `div`. A long title is cut off with an ellipsis.

### CodeBlockActions

Renders a `div`. It floats over the corner when it is a direct child of `CodeBlock`.

### CodeBlockCopyButton

Accepts the props of `Button`.

| Prop | Type | Default |
| --- | --- | --- |
| `value` | `string` (required) | - |
| `className` | `string` | - |

The button is labelled "Copy", and a live region says "Copied".

### CodeBlockContent

Renders a `pre` with a `code` inside. It is always `dir="ltr"`.

| Prop | Type | Default |
| --- | --- | --- |
| `children` | `string \| ReactNode` (a list of `CodeBlockLine`) | - |
| `wrap` | `boolean` | `false` |
| `lineNumbers` | `boolean` | `false` |
| `startLine` | `number` | `1` |
| `tabIndex` | `number` | `0` |
| `className` | `string` | - |

### CodeBlockLine

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `"default" \| "added" \| "removed" \| "highlighted"` | `"default"` |
| `className` | `string` | - |

### useHighlightedCode

```ts
function useHighlightedCode(code: string, language: string): ReactNode[]
```

Returns one node per line. `code` ignores one trailing newline. `language` is a language, an alias, or `"ansi"`.

### highlightCode

```ts
function highlightCode(code: string, language: string): Promise<ReactNode[] | null>
```

## Accessibility

- The content is a `pre` with a `code` element, always `dir="ltr"`.
- The content is focusable by default (`tabIndex={0}`), so the keyboard can scroll it.
- Floating actions show on focus as well as on hover.
- Line numbers are drawn by CSS, so screen readers do not read them.
- Diff markers go with the tints, so a change does not rely on colour alone.
