## Usage

```tsx
import {
  Trace,
  TraceCollapsible,
  TraceCollapsibleContent,
  TraceCollapsibleTrigger,
  TraceDescription,
  TraceIcon,
  TraceLine,
  TraceTitle,
} from "@/components/nepui/trace"
```

```tsx
<Trace>
  <TraceLine>
    <TraceIcon><SearchIcon /></TraceIcon>
    <TraceTitle>Searched for minimumReleaseAge</TraceTitle>
  </TraceLine>
</Trace>
```

Use `Trace` for agent steps: tool calls, subagents and file edits. The icons are decorative, so the title has to say everything. Write full sentences. Colours come from tokens, so dark mode needs no extra setup. Icons are your own: use inline SVG or any icon library.

## Composition

```text
Trace
└── TraceLine
    ├── TraceIcon
    ├── TraceTitle
    ├── TraceDescription
    └── TraceIcon
```

The first `TraceIcon` names the action and the last one is an indicator, such as an arrow on a link.

```text
Trace
└── TraceCollapsible
    ├── TraceCollapsibleTrigger
    │   └── TraceLine
    └── TraceCollapsibleContent
```

## Status

Use `status` on `TraceLine`.

| Status | Use for |
| --- | --- |
| none | Finished work |
| `"error"` | Failed work |
| `"running"` | In progress. The title shimmers. |
| `"pending"` | Not started, such as a plan step |

Put the status in the title as well, because colour and motion alone do not convey it. Write present tense for `running`.

## Collapsible

Wrap a `TraceLine` in `TraceCollapsibleTrigger` and put the detail in `TraceCollapsibleContent`. The trigger is a button with `aria-expanded` and adds a chevron after the line. Rows start closed. Use `defaultOpen` to start open, or `open` with `onOpenChange` to control it.

```tsx
const [open, setOpen] = React.useState<boolean>()

<TraceCollapsible open={open ?? running} onOpenChange={setOpen}>
  ...
</TraceCollapsible>
```

## Link

Wrap a `TraceLine` in an `<a>` or a `<button>` with the `np-trace-link` class. For a link that opens in a new tab, add screen reader text with `np-trace-sr-only`. The same wrapper works as the trigger of a [Dialog](/docs/components/react/dialog) or a [Sheet](/docs/components/react/sheet): use `render={<button className="np-trace-link" />}` on the trigger.

## Accessibility

- A bare line is a `span`: it is read as text and is not a tab stop.
- Inside a collapsible trigger it becomes a button that announces whether it is expanded.
- Inside a link, or a dialog or sheet trigger, it takes that element's keyboard and focus behaviour.
- Icons are hidden from assistive technology, so the title is the accessible name.
- Add `np-trace-sr-only` text "(opens in a new tab)" to links that open a new tab.
- The title shimmer stops for users who prefer reduced motion.

## API Reference

### Trace

Renders a `<div>`. Accepts native `div` props.

### TraceLine

| Prop | Type | Default |
| --- | --- | --- |
| `status` | `"running" \| "error" \| "pending"` | - |
| `className` | `string` | - |

Renders a `<span>`. `traceLineVariants` is exported too.

### TraceIcon

Renders a decorative `<span>`, hidden from assistive technology.

### TraceTitle

Renders a `<span>`. A single line that truncates, and shimmers while running.

### TraceDescription

Renders a `<span>`. Secondary text that does not truncate.

### TraceCollapsible

Wraps [Base UI Collapsible.Root](https://base-ui.com/react/components/collapsible).

| Prop | Type | Default |
| --- | --- | --- |
| `open` | `boolean` | - |
| `defaultOpen` | `boolean` | `false` |
| `onOpenChange` | `(open: boolean) => void` | - |

### TraceCollapsibleTrigger

Renders a `<button>` with a chevron after the line.

### TraceCollapsibleContent

| Prop | Type | Default |
| --- | --- | --- |
| `keepMounted` | `boolean` | `false` |
