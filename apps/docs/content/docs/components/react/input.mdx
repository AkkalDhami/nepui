## Usage

```tsx
import { Input } from "@/components/nepui/input";
```

```tsx
<Input id="name" name="name" placeholder="Enter your name" size="sm" />
<Input id="email" name="email" placeholder="Enter your email" />
<Input
  id="password"
  name="password"
  placeholder="Enter your password"
  size="lg"
/>
```

## API Reference

| Prop        | Type                                | Default     |
| ----------- | ----------------------------------- | ----------- |
| `size`      | `"xs" \| "sm" \| "default" \| "lg"` | `"default"` |
| `className` | `string \| (state) => string`       | —           |
 
All other props are passed to [Base UI's](https://base-ui.com/react/components/input#api-reference) `Input` and the underlying `<input>`.
