## Usage

```tsx
import {
  Progress,
  ProgressLabel,
  ProgressValue,
} from "@/components/nepui/progress"
```

```tsx
<Progress value={33} aria-label="Progress" />
```

---

## Composition

Use the following composition to build a `Progress` with a label and a value:

```text
Progress
├── ProgressLabel
├── ProgressValue
└── ProgressTrack
    └── ProgressIndicator
```

`ProgressTrack` and `ProgressIndicator` are added by `Progress` after your children. You only write them yourself when you build the parts by hand with Base UI's `Progress.Root`.

---

## Label

Use `ProgressLabel` and `ProgressValue` to add a label and a value display.

<ComponentPreview
  name="progress-label"
/>

`ProgressValue` shows the formatted value, for example `56%`. Use the `format` and `locale` props of `Progress` to change it.

## Indeterminate

Set `value` to `null` when you don't know how long the task will take. The indicator slides along the track, and `data-indeterminate` is set on the parts.

<ComponentPreview
  name="progress-indeterminate"
/>

```tsx
<Progress value={null} aria-label="Loading" />
```

The animation is turned off for users who prefer reduced motion.

## API Reference

All parts are built on Base UI's [Progress](https://base-ui.com/react/components/progress#api-reference). Every prop of the matching Base UI part is accepted.

### Progress
 
| Prop              | Type                            | Default |
| ----------------- | ------------------------------- | ------- |
| `value`           | `number \| null`                | —       |
| `min`             | `number`                        | `0`     |
| `max`             | `number`                        | `100`   |
| `format`          | `Intl.NumberFormatOptions`      | —       |
| `locale`          | `Intl.LocalesArgument`          | —       |
| `className` | `string \| (state) => string` | —       |

### ProgressLabel
 
An accessible label for the bar. Base UI connects it to the root.
 
| Prop        | Type                          | Default |
| ----------- | ----------------------------- | ------- |
| `className` | `string \| (state) => string` | —       |
 
### ProgressValue
 
The formatted value. It accepts a render function as `children` to show something else.
 
| Prop        | Type                                                        | Default |
| ----------- | ----------------------------------------------------------- | ------- |
| `children`  | `(formattedValue: string \| null, value: number \| null) => ReactNode` | — |
| `className` | `string \| (state) => string`                               | —       |
 
### ProgressTrack
 
The rail that represents the whole task.
 
| Prop        | Type                          | Default |
| ----------- | ----------------------------- | ------- |
| `className` | `string \| (state) => string` | —       |
 
### ProgressIndicator
 
The filled part of the track.
 
| Prop        | Type                          | Default |
| ----------- | ----------------------------- | ------- |
| `className` | `string \| (state) => string` | —       |
