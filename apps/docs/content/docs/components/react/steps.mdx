## Usage

```tsx
import { Step, Steps } from "@/components/nepui/steps"
```

```tsx
<Steps>
  <Step>Copy and paste the following code into your project.</Step>
 
  Add the stylesheet to your project.
 
  <Step>Update the import paths to match your project setup.</Step>
 
  Check that the tokens file is imported before the component.
 
  <Step>Use the component.</Step>
</Steps>
```

## Markdown headings
 
Any direct `h3` inside `Steps` is numbered too, so you can write plain
markdown headings.

```mdx
<Steps>
 
### Install the package
 
Run the install command.
 
### Import the styles
 
Import the stylesheet once in your root layout.
 
</Steps>
```
 
Leave a blank line after `<Steps>` and before `</Steps>` so MDX parses the
content as markdown.

## Register in MDX
 
To use `Steps` and `Step` in every docs page without importing them, add them
to your MDX components map. The exact file depends on your framework.
 
```tsx
import { Step, Steps } from "@/components/nepui/steps"
 
export function useMDXComponents(components) {
  return { Step, Steps, ...components }
}
```
