## Usage

```tsx showLineNumbers
import {
  Tabs,
  TabsContent,
  TabsList,
  TabsTrigger,
} from "@/components/nepui/tabs"
```

```tsx showLineNumbers
<Tabs defaultValue="account" className="w-[400px]">
  <TabsList>
    <TabsTrigger value="account">Account</TabsTrigger>
    <TabsTrigger value="password">Password</TabsTrigger>
  </TabsList>
  <TabsContent value="account">Make changes to your account here.</TabsContent>
  <TabsContent value="password">Change your password here.</TabsContent>
</Tabs>
```

Each `TabsTrigger` needs a `value`, and the `TabsContent` with the same `value` is shown while it is active. To control the active tab yourself, pass `value` and `onValueChange` to `Tabs`.

```tsx showLineNumbers
const [tab, setTab] = useState("account")

<Tabs value={tab} onValueChange={setTab}>
  ...
</Tabs>
```

By default the arrow keys move focus between tabs, and Enter or Space selects the focused one. Pass `activateOnFocus` to `TabsList` to select as you move.

The default list uses a translucent active tab in dark mode, and the `line` variant stays transparent. Colours come from tokens, so no extra setup is needed. The styles use `color-mix()` and logical inset properties, which need a modern browser.

## Composition

Use the following composition to build `Tabs`:

```text
Tabs
├── TabsList
│   ├── TabsTrigger
│   └── TabsTrigger
├── TabsContent
└── TabsContent
```

## Vertical

Use `orientation="vertical"` on `Tabs` to stack the triggers beside the panel. The arrow keys switch to Up and Down. It works with `variant="line"` too, and the indicator moves to the side.

## API Reference

### Tabs

Wraps [Base UI Tabs.Root](https://base-ui.com/react/components/tabs). Renders a `<div>`.

| Prop | Type | Default |
| --- | --- | --- |
| `defaultValue` | `string \| number \| null` | `0` |
| `value` | `string \| number \| null` | - |
| `onValueChange` | `(value, eventDetails) => void` | - |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` |
| `className` | `string \| (state) => string` | - |

### TabsList

Renders a `<div>` with `role="tablist"`.

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `"default" \| "line"` | `"default"` |
| `activateOnFocus` | `boolean` | `false` |
| `loopFocus` | `boolean` | `true` |
| `className` | `string \| (state) => string` | - |

### TabsTrigger

Renders a `<button>` with `role="tab"`.

| Prop | Type | Default |
| --- | --- | --- |
| `value` | `string \| number` | - |
| `disabled` | `boolean` | `false` |
| `nativeButton` | `boolean` | `true` |
| `className` | `string \| (state) => string` | - |

`value` is required. Set `nativeButton` to `false` when you `render` a non-button element, such as a link.

### TabsContent

Renders a `<div>` with `role="tabpanel"`.

| Prop | Type | Default |
| --- | --- | --- |
| `value` | `string \| number` | - |
| `keepMounted` | `boolean` | `false` |
| `className` | `string \| (state) => string` | - |

`value` is required. Set `keepMounted` to keep an inactive panel in the DOM.
