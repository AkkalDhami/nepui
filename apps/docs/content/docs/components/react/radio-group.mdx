## Usage

```tsx
import { RadioGroup, RadioGroupItem } from "@/components/nepui/radio-group"
```

```tsx
<RadioGroup defaultValue="comfortable" aria-label="Density">
  <RadioGroupItem value="default" aria-label="Default" />
  <RadioGroupItem value="comfortable" aria-label="Comfortable" />
  <RadioGroupItem value="compact" aria-label="Compact" />
</RadioGroup>
```

Give every item a visible label (with `id` and `htmlFor`) or an `aria-label`, and give the group an `aria-label` or a legend.

---

## Composition
Use the following composition to build a `RadioGroup`:

```text
RadioGroup
├── RadioGroupItem
└── RadioGroupItem
```

## Invalid

Add `data-invalid` to the `Field` and `aria-invalid` to the `RadioGroupItem` to show an error state.

```tsx showLineNumbers /data-invalid/ /aria-invalid/
<Field orientation="horizontal" data-invalid>
  <RadioGroupItem value="email" id="email" aria-invalid />
  <FieldLabel htmlFor="email">Email</FieldLabel>
</Field>
```

## API Reference

### RadioGroup

| Prop | Type | Default |
| ---- | ---- | ------- |
| `orientation` | `"vertical" \| "horizontal"` | `"vertical"` |
| `value` | `string` | - |
| `defaultValue` | `string` | - |
| `onValueChange` | `(value: string, eventDetails) => void` | - |
| `disabled` | `boolean` | `false` |
| `readOnly` | `boolean` | `false` |
| `required` | `boolean` | `false` |
| `name` | `string` | - |

`RadioGroup` also accepts the other props of the Base UI [Radio Group](https://base-ui.com/react/components/radio).

### RadioGroupItem

| Prop | Type | Default |
| ---- | ---- | ------- |
| `value` | `string` | - |
| `disabled` | `boolean` | `false` |
| `id` | `string` | - |
| `aria-invalid` | `boolean` | `false` |
