## Usage

```tsx
import {
  Item,
  ItemActions,
  ItemContent,
  ItemDescription,
  ItemMedia,
  ItemTitle,
} from "@/components/nepui/item"
```

```tsx
<Item>
  <ItemMedia variant="icon">
    <Icon />
  </ItemMedia>
  <ItemContent>
    <ItemTitle>Title</ItemTitle>
    <ItemDescription>Description</ItemDescription>
  </ItemContent>
  <ItemActions>
    <Button>Action</Button>
  </ItemActions>
</Item>
```

The `Item` component is a straightforward flex container that can house nearly any type of content. Use it to display a title, description, and actions. Group it with the `ItemGroup` component to create a list of items.

---

## Composition

Use the following composition to build an `Item`:

```text
ItemGroup
└── Item
    ├── ItemHeader
    ├── ItemMedia
    ├── ItemContent
    │   ├── ItemTitle
    │   └── ItemDescription
    ├── ItemActions
    └── ItemFooter
```

---

## Item vs Field

Use [Field](/docs/components/react/field) if you need to display a form input such as a checkbox, input, radio, or select.

If you only need to display content such as a title, description, and actions, use `Item`.

## Link

Use the `render` prop to render the item as a link. The hover and focus states are applied to the anchor element. Render it as a `button` the same way.

<ComponentPreview
  name="item-link"
/>

An item rendered with `render` does not get `role="listitem"`, so do not put it directly inside an `ItemGroup`. Wrap it in your own `div role="listitem"` if you need a list.

---

## States

Add `aria-current` (or `data-selected`) to mark an item as selected. A link, button or `data-interactive` item gets hover styles. `aria-disabled="true"` (or `data-disabled`, or a disabled button) dims it and blocks pointer events.

## API Reference

### Item

The main component for displaying content with media, title, description, and actions. It renders a `div` and accepts every `div` prop.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `variant` | `"default" \| "outline" \| "muted"` | `"default"` |
| `size` | `"default" \| "sm" \| "xs"` | `"default"` |
| `render` | `ReactElement \| (props, state) => ReactElement` | - |
| `className` | `string` | - |

`itemVariants` is exported too, so you can give the same look to a non-React element.

### ItemGroup

A container that groups related items together. It renders a `div` with `role="list"`.

```tsx
<ItemGroup>
  <Item />
  <Item />
</ItemGroup>
```

### ItemSeparator

A separator between items in a group. It renders the nepui `Separator`.

```tsx
<ItemGroup>
  <Item />
  <ItemSeparator />
  <Item />
</ItemGroup>
```

### ItemMedia

Use `ItemMedia` to display media content such as icons, images, or avatars.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `variant` | `"default" \| "icon" \| "image"` | `"default"` |
| `className` | `string` | - |

```tsx
<ItemMedia variant="icon">
  <Icon />
</ItemMedia>
```

```tsx
<ItemMedia variant="image">
  <img src="..." alt="..." />
</ItemMedia>
```

### ItemContent

Wraps the title and description of the item. It takes the remaining width.

```tsx
<ItemContent>
  <ItemTitle>Title</ItemTitle>
  <ItemDescription>Description</ItemDescription>
</ItemContent>
```

### ItemTitle

Displays the title of the item.

### ItemDescription

Displays the description of the item. It is clamped to two lines, which `--np-item-description-lines` changes.

### ItemActions

Container for action buttons or other interactive elements.

### ItemHeader

Displays a header above the item content.

### ItemFooter

Displays a footer below the item content.
