## Usage

```tsx
import { Slider } from "@/components/nepui/slider"
```

```tsx
<Slider defaultValue={[33]} max={100} step={1} aria-label="Volume" />
```

## API Reference

### Slider

| Prop | Type | Default |
| ---- | ---- | ------- |
| `value` | `number \| number[]` | - |
| `defaultValue` | `number \| number[]` | - |
| `onValueChange` | `(value, eventDetails) => void` | - |
| `onValueCommitted` | `(value, eventDetails) => void` | - |
| `min` | `number` | `0` |
| `max` | `number` | `100` |
| `step` | `number` | `1` |
| `largeStep` | `number` | `10` |
| `minStepsBetweenValues` | `number` | `0` |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` |
| `thumbAlignment` | `"center" \| "edge" \| "edge-client-only"` | `"edge"` |
| `disabled` | `boolean` | `false` |
| `name` | `string` | - |

`Slider` also accepts the other props of the [Base UI Slider](https://base-ui.com/react/components/slider#api-reference).
