## Usage

```tsx
import {
  Accordion,
  AccordionContent,
  AccordionItem,
  AccordionTrigger,
} from "@/components/nepui/accordion"
```

```tsx
<Accordion defaultValue={["item-1"]}>
  <AccordionItem value="item-1">
    <AccordionTrigger>Is it accessible?</AccordionTrigger>
    <AccordionContent>
      Yes. It adheres to the WAI-ARIA design pattern.
    </AccordionContent>
  </AccordionItem>
</Accordion>
```

`value` and `defaultValue` are always arrays of the open items' `value`s, for example `["item-1"]`.

## Composition

Use the following composition to build an `Accordion`:

```text
Accordion
├── AccordionItem
│   ├── AccordionTrigger
│   └── AccordionContent
└── AccordionItem
    ├── AccordionTrigger
    └── AccordionContent
```

`AccordionTrigger` renders the heading that wraps the button, so you do not add one yourself. The chevron is drawn by the stylesheet.

## Custom icon

The chevron is a CSS mask, so any icon works. Set `--np-accordion-icon` to a `url()` and, for an icon that should not flip, set `--np-accordion-icon-rotate-open` to `0deg`.

```tsx
<Accordion
  style={{
    "--np-accordion-icon": 'url("/icons/plus.svg")',
    "--np-accordion-icon-rotate-open": "45deg",
  } as CSSProperties}
>
  ...
</Accordion>
```

## API Reference

Built on the [Base UI Accordion](https://base-ui.com/react/components/accordion#api-reference). All Base UI props are supported, the tables list the ones you will use most.

### Accordion

| Prop            | Type                                                                      | Default     |
| --------------- | ------------------------------------------------------------------------- | ----------- |
| `variant`       | `"default" \| "bordered"`                                                 | `"default"` |
| `multiple`      | `boolean`                                                                 | `false`     |
| `value`         | `string[]`                                                                | -           |
| `defaultValue`  | `string[]`                                                                | -           |
| `onValueChange` | `(value: string[], eventDetails: Accordion.Root.ChangeEventDetails) => void` | -        |
| `disabled`      | `boolean`                                                                 | `false`     |
| `loopFocus`     | `boolean`                                                                 | `true`      |
| `keepMounted`   | `boolean`                                                                 | `false`     |
| `className`     | `string \| (state) => string`                                             | -           |

### AccordionItem

| Prop           | Type                                | Default |
| -------------- | ----------------------------------- | ------- |
| `value`        | `string`                            | -       |
| `disabled`     | `boolean`                           | `false` |
| `onOpenChange` | `(open: boolean) => void`           | -       |
| `className`    | `string \| (state) => string`       | -       |

### AccordionTrigger

| Prop        | Type                          | Default |
| ----------- | ----------------------------- | ------- |
| `className` | `string \| (state) => string` | -       |

### AccordionContent

| Prop              | Type                          | Default |
| ----------------- | ----------------------------- | ------- |
| `keepMounted`     | `boolean`                     | `false` |
| `hiddenUntilFound` | `boolean`                    | `false` |
| `className`       | `string \| (state) => string` | -       |
