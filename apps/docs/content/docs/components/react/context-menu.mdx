## Usage

```tsx
import {
  ContextMenu,
  ContextMenuContent,
  ContextMenuItem,
  ContextMenuTrigger,
} from "@/components/nepui/context-menu"
```

```tsx
<ContextMenu>
  <ContextMenuTrigger>Right click here</ContextMenuTrigger>
  <ContextMenuContent>
    <ContextMenuItem>Profile</ContextMenuItem>
    <ContextMenuItem>Billing</ContextMenuItem>
    <ContextMenuItem>Team</ContextMenuItem>
    <ContextMenuItem>Subscription</ContextMenuItem>
  </ContextMenuContent>
</ContextMenu>
```

## Composition

Use the following composition to build a context menu:

```text
ContextMenu
├── ContextMenuTrigger
└── ContextMenuContent
    ├── ContextMenuLabel
    ├── ContextMenuItem
    ├── ContextMenuGroup
    │   └── ContextMenuItem
    ├── ContextMenuCheckboxItem
    ├── ContextMenuRadioGroup
    │   └── ContextMenuRadioItem
    ├── ContextMenuSub
    │   ├── ContextMenuSubTrigger
    │   └── ContextMenuSubContent
    ├── ContextMenuSeparator
    └── ContextMenuShortcut
```

## API Reference

### ContextMenu and ContextMenuTrigger

The root has no element of its own. The trigger is the area that opens the menu on right click or long press. Both accept the props of the Base UI [Context Menu](https://base-ui.com/react/components/context-menu).

| Prop | Type | Default |
| ---- | ---- | ------- |
| `className` (trigger) | `string \| (state) => string` | - |

### ContextMenuContent

The menu. It is rendered in a portal and placed at the pointer.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `side` | `"top" \| "right" \| "bottom" \| "left" \| "inline-start" \| "inline-end"` | `"right"` |
| `sideOffset` | `number` | `0` |
| `align` | `"start" \| "center" \| "end"` | `"start"` |
| `alignOffset` | `number` | `4` |
| `className` | `string \| (state) => string` | - |

### ContextMenuItem

| Prop | Type | Default |
| ---- | ---- | ------- |
| `variant` | `"default" \| "destructive"` | `"default"` |
| `inset` | `boolean` | `false` |
| `disabled` | `boolean` | `false` |
| `onClick` | `(event) => void` | - |
| `className` | `string \| (state) => string` | - |

### ContextMenuCheckboxItem

| Prop | Type | Default |
| ---- | ---- | ------- |
| `checked` | `boolean` | - |
| `defaultChecked` | `boolean` | `false` |
| `onCheckedChange` | `(checked, eventDetails) => void` | - |
| `inset` | `boolean` | `false` |
| `disabled` | `boolean` | `false` |

### ContextMenuRadioGroup and ContextMenuRadioItem

| Prop | Type | Default |
| ---- | ---- | ------- |
| `value` (group) | `string` | - |
| `defaultValue` (group) | `string` | - |
| `onValueChange` (group) | `(value, eventDetails) => void` | - |
| `value` (item) | `string` | - |
| `inset` (item) | `boolean` | `false` |

### ContextMenuSub, ContextMenuSubTrigger and ContextMenuSubContent

`ContextMenuSubTrigger` takes `inset`. `ContextMenuSubContent` takes the same props as `ContextMenuContent`, and opens to the `right` by default.

### ContextMenuLabel, ContextMenuSeparator, ContextMenuGroup and ContextMenuShortcut

| Prop | Type | Default |
| ---- | ---- | ------- |
| `inset` (label) | `boolean` | `false` |
| `className` | `string` | - |
