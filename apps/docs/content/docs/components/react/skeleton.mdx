## Usage

```tsx
import { Skeleton } from "@/components/nepui/skeleton"
```

```tsx
<Skeleton style={{ width: "12rem", height: "1rem" }} />
```

## Shape

Add the `np-skeleton-circle` class for a round skeleton, such as an avatar.

<ComponentPreview
  name="skeleton-shape"
/>

```tsx
<Skeleton
  className="np-skeleton-circle"
  style={{ width: "3rem", height: "3rem" }}
/>
```

## API Reference

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | —       |
| `style`     | `React.CSSProperties` | — |

All other props are passed to the underlying `div`.
