## Usage

```tsx
import {
  Menu,
  MenuContent,
  MenuGroup,
  MenuItem,
  MenuLabel,
  MenuSeparator,
  MenuTrigger,
} from "@/components/nepui/menu"
```

```tsx
<Menu>
  <MenuTrigger render={<Button variant="outline" />}>Open</MenuTrigger>
  <MenuContent>
    <MenuGroup>
      <MenuLabel>My Account</MenuLabel>
      <MenuItem>Profile</MenuItem>
      <MenuItem>Billing</MenuItem>
    </MenuGroup>
    <MenuSeparator />
    <MenuItem>Log out</MenuItem>
  </MenuContent>
</Menu>
```

`Menu` is built on Base UI's [Menu](https://base-ui.com/react/components/menu). It handles focus, keyboard navigation (arrow keys, `Home`, `End`, typeahead), `Escape` and click-outside for you.

`MenuLabel` must be inside a `MenuGroup`.

```text
    ├── MenuRadioGroup
    │   └── MenuRadioItem
    └── MenuSub
        ├── MenuSubTrigger
        └── MenuSubContent
```

## Basic

A menu with a group label, a few items and a separator. Set the width of the menu with `style` or `className` on `MenuContent`. By default it is as wide as its content, with a minimum of `8rem`, and never narrower than the trigger.

## API Reference

All parts are built on Base UI's [Menu](https://base-ui.com/react/components/menu#api-reference). Every prop of the matching Base UI part is accepted.

### Menu

The root. It holds the open state.

| Prop           | Type                      | Default |
| -------------- | ------------------------- | ------- |
| `open`         | `boolean`                 | —       |
| `defaultOpen`  | `boolean`                 | `false` |
| `onOpenChange` | `(open: boolean) => void` | —       |
| `modal`        | `boolean`                 | `true`  |
| `disabled`     | `boolean`                 | `false` |

### MenuTrigger

The button that opens the menu. Use `render` to render your own element, such as a [Button](/docs/components/react/button).

| Prop     | Type                             | Default |
| -------- | -------------------------------- | ------- |
| `render` | `React.ReactElement \| function` | —       |

### MenuContent

The popup. It portals, positions and animates itself.

| Prop          | Type                                                                | Default    |
| ------------- | ------------------------------------------------------------------- | ---------- |
| `side`        | `"top" \| "bottom" \| "left" \| "right" \| "inline-start" \| "inline-end"` | `"bottom"` |
| `align`       | `"start" \| "center" \| "end"`                                      | `"start"`  |
| `sideOffset`  | `number`                                                            | `4`        |
| `alignOffset` | `number`                                                            | `0`        |
| `className`   | `string \| (state) => string`                                       | —          |

### MenuGroup

Groups related items. Give it a `MenuLabel` to name it.

### MenuLabel

A heading for a group. It must be inside a `MenuGroup`.

| Prop    | Type      | Default |
| ------- | --------- | ------- |
| `inset` | `boolean` | `false` |

### MenuItem

An action.

| Prop           | Type                        | Default     |
| -------------- | --------------------------- | ----------- |
| `variant`      | `"default" \| "destructive"` | `"default"` |
| `inset`        | `boolean`                   | `false`     |
| `disabled`     | `boolean`                   | `false`     |
| `closeOnClick` | `boolean`                   | `true`      |
| `onClick`      | `(event) => void`           | —           |

### MenuCheckboxItem

An item that toggles. It does not close the menu when clicked.

| Prop              | Type                         | Default |
| ----------------- | ---------------------------- | ------- |
| `checked`         | `boolean`                    | —       |
| `defaultChecked`  | `boolean`                    | `false` |
| `onCheckedChange` | `(checked: boolean) => void` | —       |
| `inset`           | `boolean`                    | `false` |
| `disabled`        | `boolean`                    | `false` |

### MenuRadioGroup

Groups radio items and holds the chosen value.

| Prop            | Type                      | Default |
| --------------- | ------------------------- | ------- |
| `value`         | `string`                  | —       |
| `defaultValue`  | `string`                  | —       |
| `onValueChange` | `(value: string) => void` | —       |

### MenuRadioItem

One option of a radio group.

| Prop       | Type      | Default |
| ---------- | --------- | ------- |
| `value`    | `string`  | —       |
| `inset`    | `boolean` | `false` |
| `disabled` | `boolean` | `false` |
