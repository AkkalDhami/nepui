## Usage

```tsx
import {
  Carousel,
  CarouselContent,
  CarouselItem,
  CarouselNext,
  CarouselPrevious,
} from "@/components/nepui/carousel"
```

```tsx
<Carousel>
  <CarouselContent>
    <CarouselItem>...</CarouselItem>
    <CarouselItem>...</CarouselItem>
    <CarouselItem>...</CarouselItem>
  </CarouselContent>
  <CarouselPrevious />
  <CarouselNext />
</Carousel>
```

The carousel is built on [Embla Carousel](https://www.embla-carousel.com), so you get drag, loop, autoplay and an API. The buttons sit `3rem` outside the root, so leave room on both sides, for example with a margin. Colours come from tokens, so dark mode needs no extra setup.

## Options

Use the `opts` prop to pass [Embla options](https://www.embla-carousel.com/api/options/).

```tsx
<Carousel opts={{ align: "start", loop: true }}>
  ...
</Carousel>
```

## Events

Subscribe to events on the API instance:

```tsx
React.useEffect(() => {
  if (!api) return

  api.on("select", () => {
    // Do something on select.
  })
}, [api])
```

---

## Plugins

Use the `plugins` prop to pass [Embla plugins](https://www.embla-carousel.com/docs/plugins), such as Autoplay.

```tsx
import Autoplay from "embla-carousel-autoplay"

<Carousel plugins={[Autoplay({ delay: 2000 })]}>
  ...
</Carousel>
```

## Accessibility

- The root is a `region` with `aria-roledescription="carousel"`; give it an `aria-label`. Each slide is a `group` with `aria-roledescription="slide"`.
- The previous and next buttons have labels and are disabled at the ends.
- Arrow keys step through the slides when focus is inside the carousel.

## API Reference

### Carousel

Renders a `<div>`.

| Prop | Type | Default |
| --- | --- | --- |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` |
| `opts` | Embla options | - |
| `plugins` | Embla plugins | - |
| `setApi` | `(api: CarouselApi) => void` | - |
| `dir` | `"ltr" \| "rtl"` | - |

### CarouselContent

Renders the clipping viewport and the row inside it. `className` goes on the row.

### CarouselItem

Renders a `<div>` with `role="group"`.

### CarouselPrevious / CarouselNext

Render a nepui [Button](/docs/components/react/button), `outline` and `icon-sm` by default, and accept its props. They are disabled when the carousel cannot scroll that way.

`useCarousel` and the `CarouselApi` type are exported too.
