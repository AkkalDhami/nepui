## Usage

```tsx
import {
  Meter,
  MeterIndicator,
  MeterLabel,
  MeterTrack,
  MeterValue,
} from "@/components/nepui/meter"
```

```tsx
<Meter value={40}>
  <MeterLabel>Progress</MeterLabel>
  <MeterValue />
  <MeterTrack>
    <MeterIndicator />
  </MeterTrack>
</Meter>
```

The label and the value share the first row, and the track fills the second row. The order of the parts in your JSX does not matter.

## API Reference

### Meter

| Prop | Type | Default |
| ---- | ---- | ------- |
| `value` | `number` | - |
| `min` | `number` | `0` |
| `max` | `number` | `100` |
| `variant` | `"default" \| "success" \| "warning" \| "destructive"` | `"default"` |
| `size` | `"sm" \| "default" \| "lg"` | `"default"` |

`Meter` also accepts the other props of the Base UI [Meter root](https://base-ui.com/react/components/meter#api-reference).
