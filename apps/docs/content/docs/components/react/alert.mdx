## Usage

```tsx
import {
  Alert,
  AlertAction,
  AlertDescription,
  AlertTitle,
} from "@/components/nepui/alert"
```

```tsx
<Alert>
  <InfoIcon />
  <AlertTitle>Heads up!</AlertTitle>
  <AlertDescription>
    You can add components and dependencies to your app using the cli.
  </AlertDescription>
  <AlertAction>
    <Button size="xs">Enable</Button>
  </AlertAction>
</Alert>
```

Any `svg` placed directly inside the alert is used as the icon. Nepui components don't ship an icon library, so bring your own.

## API Reference

### Alert

The `Alert` component displays a callout for user attention. It renders a `div` with `role="alert"`.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `variant` | `"default" \| "success" \| "error" \| "warning" \| "info" \| "destructive"` | `"default"` |
| `className` | `string` | - |

### AlertTitle

The title of the alert.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `className` | `string` | - |

### AlertDescription

The description or content of the alert.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `className` | `string` | - |

### AlertAction

An action element, positioned in the top end corner of the alert.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `className` | `string` | - |
