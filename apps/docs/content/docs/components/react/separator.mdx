
## API Reference

| Prop          | Type                          | Default        |
| ------------- | ----------------------------- | -------------- |
| `orientation` | `"horizontal" \| "vertical"`  | `"horizontal"` |
| `className` | `string` | — |

All other props are inherited from Base UI's [Separator](https://base-ui.com/react/components/separator).
