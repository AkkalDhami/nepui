## Usage

```tsx
import { Checkbox } from "@/components/nepui/checkbox"
import { CheckboxGroup } from "@/components/nepui/checkbox-group"
import { Label } from "@/components/nepui/label"
```

```tsx
<CheckboxGroup aria-label="Select frameworks" defaultValue={["next"]}>
  <Label>
    <Checkbox value="next" />
    Next.js
  </Label>
  <Label>
    <Checkbox value="vite" />
    Vite
  </Label>
  <Label>
    <Checkbox value="astro" />
    Astro
  </Label>
</CheckboxGroup>
```

Every checkbox needs an accessible name. Wrap it in a `Label`, and name the group with `aria-label` or `aria-labelledby`. To validate or label the group as a form field, wrap it with the [Field](/docs/components/react/field) components.

## Parent checkbox

A checkbox that controls the others in the group:

1. Make the group controlled with `value` and `onValueChange`.
2. Pass every child value to `allValues`.
3. Add the `parent` prop to the parent `Checkbox`.

The group sets the parent's indeterminate state when only some children are checked. Add the `np-checkbox-group-child` class to indent the children.

## API Reference

This component wraps the [Base UI Checkbox Group](https://base-ui.com/react/components/checkbox-group#api-reference) and accepts all of its props.

### CheckboxGroup

| Prop | Type | Default |
| ---- | ---- | ------- |
| `value` | `string[]` | - |
| `defaultValue` | `string[]` | - |
| `onValueChange` | `(value: string[], eventDetails) => void` | - |
| `allValues` | `string[]` | - |
| `disabled` | `boolean` | `false` |
| `orientation` | `"vertical" \| "horizontal"` | `"vertical"` |
