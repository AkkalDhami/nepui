## Usage

```tsx
import {
  NumberInput,
  NumberInputDecrement,
  NumberInputGroup,
  NumberInputIncrement,
  NumberInputInput,
  NumberInputScrubArea,
} from "@/components/nepui/number-input"
```

```tsx
<NumberInput defaultValue={0}>
  <NumberInputScrubArea label="Quantity" />
  <NumberInputGroup>
    <NumberInputDecrement />
    <NumberInputInput />
    <NumberInputIncrement />
  </NumberInputGroup>
</NumberInput>
```

## Composition

```text
NumberInput
├── NumberInputScrubArea (optional)
└── NumberInputGroup
    ├── NumberInputDecrement
    ├── NumberInputInput
    └── NumberInputIncrement
```

`NumberInput` wraps the Base UI `NumberField.Root`, so every Base UI root prop works here: `value`, `onValueChange`, `min`, `max`, `step`, `format`, `locale` and the rest. See the [Base UI reference](https://base-ui.com/react/components/number-field#api-reference).

`step` sets the amount for buttons, arrow keys and scrubbing. Hold `Shift` for `largeStep` (default 10) and `Alt` for `smallStep` (default 0.1).

## Keyboard

| Key | Action |
| --- | --- |
| `ArrowUp` / `ArrowDown` | Increase or decrease by `step` |
| `Shift` + `ArrowUp` / `ArrowDown` | Change by `largeStep` |
| `Alt` + `ArrowUp` / `ArrowDown` | Change by `smallStep` |
| `Home` / `End` | Jump to `min` or `max` |

Set `allowWheelScrub` to step with the mouse wheel while the input is focused. The increment and decrement buttons stay out of the tab order, so the input is the only tab stop.

## API Reference

### NumberInput

Accepts every [Base UI NumberField.Root](https://base-ui.com/react/components/number-field#root) prop, plus:

| Prop | Type | Default |
| --- | --- | --- |
| `size` | `"default" \| "xs" \| "sm" \| "lg"` | `"default"` |
| `layout` | `"split" \| "stacked"` | `"split"` |
| `id` | `string` | generated |
| `className` | `string \| (state) => string` | - |

### NumberInputGroup

Draws the border, radius and focus ring around the buttons and the input.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string \| (state) => string` | - |

### NumberInputInput

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string \| (state) => string` | - |

### NumberInputIncrement

| Prop | Type | Default |
| --- | --- | --- |
| `children` | `ReactNode` | plus icon, or chevron up when stacked |
| `className` | `string \| (state) => string` | - |

### NumberInputDecrement

| Prop | Type | Default |
| --- | --- | --- |
| `children` | `ReactNode` | minus icon, or chevron down when stacked |
| `className` | `string \| (state) => string` | - |

### NumberInputScrubArea

| Prop | Type | Default |
| --- | --- | --- |
| `label` | `ReactNode` | - |
| `cursor` | `boolean` | `true` |
| `direction` | `"horizontal" \| "vertical"` | `"horizontal"` |
| `pixelSensitivity` | `number` | `2` |
| `teleportDistance` | `number` | - |
| `className` | `string \| (state) => string` | - |
