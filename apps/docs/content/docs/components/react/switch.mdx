## Invalid

Add `data-invalid` to the `Field` and `aria-invalid` to the `Switch` to show an error state.

```tsx showLineNumbers /data-invalid/ /aria-invalid/
<Field orientation="horizontal" data-invalid>
  <FieldContent>
    <FieldLabel htmlFor="terms">Accept terms and conditions</FieldLabel>
  </FieldContent>
  <Switch id="terms" aria-invalid />
</Field>
```

## API Reference

| Prop | Type | Default |
| ---- | ---- | ------- |
| `size` | `"sm" \| "default"` | `"default"` |
| `checked` | `boolean` | - |
| `defaultChecked` | `boolean` | `false` |
| `onCheckedChange` | `(checked: boolean, eventDetails) => void` | - |
| `disabled` | `boolean` | `false` |
| `readOnly` | `boolean` | `false` |
| `required` | `boolean` | `false` |
| `name` | `string` | - |

`Switch` also accepts the other props of the [Base UI Switch root](https://base-ui.com/react/components/switch#api-reference).
