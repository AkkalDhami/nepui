## Usage

```tsx
import { Kbd, KbdGroup } from "@/components/nepui/kbd"
```

```tsx
<Kbd>Esc</Kbd>
```

`Kbd` renders a semantic `<kbd>` element, so assistive technologies announce it as keyboard input.

---

## Group

Use the `KbdGroup` component to group keys together into one shortcut.

<ComponentPreview
  name="kbd-group"
/>

`KbdGroup` also renders a `<kbd>`, which wraps the keys. Nesting `<kbd>` elements is the recommended markup for key combinations.

## API Reference

### Kbd

Use the `Kbd` component to display a keyboard key.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | —       |

### KbdGroup

Use the `KbdGroup` component to group `Kbd` components together.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | —       |

All other props are passed to the underlying `kbd` element.
