## Usage

```tsx
import {
  Combobox,
  ComboboxContent,
  ComboboxEmpty,
  ComboboxInput,
  ComboboxItem,
  ComboboxList,
} from "@/components/nepui/combobox"
```

```tsx
const frameworks = ["Next.js", "SvelteKit", "Nuxt.js", "Remix", "Astro"]

export function ExampleCombobox() {
  return (
    <Combobox items={frameworks}>
      <ComboboxInput placeholder="Select a framework" aria-label="Framework" />
      <ComboboxContent>
        <ComboboxEmpty>No items found.</ComboboxEmpty>
        <ComboboxList>
          {(item) => (
            <ComboboxItem key={item} value={item}>
              {item}
            </ComboboxItem>
          )}
        </ComboboxList>
      </ComboboxContent>
    </Combobox>
  )
}
```

The input must have an accessible name. Use a visible `<label>` or an `aria-label`.

## Composition

### Simple

A single-line input and a flat list (see <LINK href="#basic">Basic</LINK>).

```text
Combobox
├── ComboboxInput
└── ComboboxContent
    ├── ComboboxEmpty
    └── ComboboxList
        ├── ComboboxItem
        └── ComboboxItem
```

### With chips

Multi-select with `multiple`, chips, and a chips input (see <LINK href="#multiple">Multiple</LINK>).

```text
Combobox
├── ComboboxChips
│   ├── ComboboxValue
│   │   └── ComboboxChip
│   └── ComboboxChipsInput
└── ComboboxContent
    ├── ComboboxEmpty
    └── ComboboxList
        ├── ComboboxItem
        └── ComboboxItem
```

### With groups and collection

Nested items per group using `ComboboxCollection` inside each `ComboboxGroup`, with a separator between groups (see <LINK href="#groups">Groups</LINK>).

```text
Combobox
├── ComboboxInput
└── ComboboxContent
    ├── ComboboxEmpty
    └── ComboboxList
        ├── ComboboxGroup
        │   ├── ComboboxLabel
        │   └── ComboboxCollection
        │       ├── ComboboxItem
        │       └── ComboboxItem
        ├── ComboboxSeparator
        └── ComboboxGroup
            ├── ComboboxLabel
            └── ComboboxCollection
                ├── ComboboxItem
                └── ComboboxItem
```

A simple combobox with a list of frameworks, as in the example at the top of this page. Type to filter, use the arrow keys to move, and press `Enter` to choose.

## Multiple

Use `multiple` with `ComboboxChips` for multi-select. Pass the ref from `useComboboxAnchor` to both `ComboboxChips` and `ComboboxContent`, so the popup is as wide as the chips box.

## API Reference

Built on the [Base UI Combobox](https://base-ui.com/react/components/combobox#api-reference). All Base UI props are supported, the tables list the ones you will use most.

### Combobox

Groups all parts of the combobox. It renders no element.

| Prop                 | Type                                         | Default |
| -------------------- | -------------------------------------------- | ------- |
| `items`              | `any[] \| Group[]`                           | -       |
| `multiple`           | `boolean`                                    | `false` |
| `value`              | `Value \| Value[] \| null`                   | -       |
| `defaultValue`       | `Value \| Value[] \| null`                   | -       |
| `onValueChange`      | `(value, eventDetails) => void`              | -       |
| `inputValue`         | `string`                                     | -       |
| `onInputValueChange` | `(value: string, eventDetails) => void`      | -       |
| `autoHighlight`      | `boolean`                                    | `false` |
| `disabled`           | `boolean`                                    | `false` |
| `itemToStringLabel`  | `(item) => string`                           | -       |
| `itemToStringValue`  | `(item) => string`                           | -       |
| `filter`             | `((item, query) => boolean) \| null`         | -       |

### ComboboxInput

The text input, inside an Input Group. Other props go to the input. Children are rendered inside the group.

| Prop          | Type      | Default |
| ------------- | --------- | ------- |
| `showTrigger` | `boolean` | `true`  |
| `showClear`   | `boolean` | `false` |
| `disabled`    | `boolean` | `false` |
| `className`   | `string`  | -       |

### ComboboxContent

The popup. Portaled and positioned by Base UI.

| Prop          | Type                                      | Default    |
| ------------- | ----------------------------------------- | ---------- |
| `side`        | `"top" \| "bottom" \| "left" \| "right"`  | `"bottom"` |
| `sideOffset`  | `number`                                  | `6`        |
| `align`       | `"start" \| "center" \| "end"`            | `"start"`  |
| `alignOffset` | `number`                                  | `0`        |
| `anchor`      | `RefObject<HTMLElement>`                  | -          |
| `className`   | `string \| (state) => string`             | -          |

### ComboboxItem

| Prop        | Type                          | Default |
| ----------- | ----------------------------- | ------- |
| `value`     | `any`                         | -       |
| `disabled`  | `boolean`                     | `false` |
| `className` | `string \| (state) => string` | -       |

### ComboboxChip

| Prop          | Type      | Default    |
| ------------- | --------- | ---------- |
| `showRemove`  | `boolean` | `true`     |
| `removeLabel` | `string`  | `"Remove"` |
