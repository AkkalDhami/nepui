## Usage

Message is pure CSS and needs no script.

```html
<link rel="stylesheet" href="./styles/avatar.css" />
<link rel="stylesheet" href="./styles/bubble.css" />
<link rel="stylesheet" href="./styles/message.css" />
```

```html
<div class="np-message">
  <div class="np-message-avatar">
    <span class="np-avatar">
      <span class="np-avatar-fallback">CN</span>
    </span>
  </div>
  <div class="np-message-content">
    <div class="np-bubble">
      <div class="np-bubble-content">How can I help you today?</div>
    </div>
  </div>
</div>
```

Or use the data attributes instead of the classes: `data-np-message`, `data-np-message-group`, `data-np-message-avatar`, `data-np-message-content`, `data-np-message-header`, `data-np-message-footer`, and `data-align="end"` for the end side.

`np-message` owns the row layout: the avatar, the alignment, the header and the footer. Render the visible message surface inside it with a Bubble.

## Composition

```text
np-message-group (optional)
└── np-message
    ├── np-message-avatar
    └── np-message-content
        ├── np-message-header (optional)
        ├── np-bubble
        │   └── np-bubble-content
        └── np-message-footer (optional)
```

## Avatar

Add `np-message-end` (or `data-align="end"`) to put the avatar and the message on the end side, as for the current user. The avatar sits on the bottom edge of the message. A Bubble inside follows the side of the message, so you do not align it yourself.

## Group

## Header and Footer

Use `np-message-header` for a sender name and `np-message-footer` for metadata such as a delivery or read status. The header stays at the start. The footer follows the side of the message. When a message has a footer, the avatar rises to stay level with the bubble instead of the footer.

<ComponentPreview
  target="html"
  name="message-header-footer"
  styles={["/avatar/avatar.css", "/bubble/bubble.css"]}
/>

The avatar offset uses the footer height. If you change one, change both with `--np-message-footer-height`.

## Accessibility

`np-message` is a presentational layout wrapper. Accessibility comes from the content you place inside it.

- Give every icon-only action in the footer an `aria-label`.
- Use `role="status"` on a Marker for in-progress messages.
- Keep the semantics of the conversation on the container around the messages, for example a labelled `role="log"` region.
