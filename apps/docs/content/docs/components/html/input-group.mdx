## Usage

Link the component's CSS file to your HTML document, along with the stylesheets of the parts you use: [Input](/docs/components/html/input), [Textarea](/docs/components/html/textarea), [Button](/docs/components/html/button) and [Kbd](/docs/components/html/kbd).

```html
<head>
  <link rel="stylesheet" href="./styles/tokens.css">
  <link rel="stylesheet" href="./styles/input.css">
  <link rel="stylesheet" href="./styles/input-group.css">
</head>
```

Then, wrap an input and its addons in an `np-input-group`. The input needs both its own class and `np-input-group-input`.

```html
<div class="np-input-group" role="group">
  <input class="np-input np-input-group-input" placeholder="Search..." aria-label="Search" />
  <div class="np-input-group-addon" role="group">
    <!-- icon -->
  </div>
  <div class="np-input-group-addon np-input-group-addon-end" role="group">12 results</div>
</div>
```

Every part also works with a `data-np-*` attribute instead of the class.

```html
<div data-np-input-group role="group">
  <input data-np-input data-np-input-group-input placeholder="Search..." aria-label="Search" />
  <div data-np-input-group-addon data-align="inline-end" role="group">12 results</div>
</div>
```

The group draws the border, the focus ring, and the invalid and disabled states. The input inside it has no border of its own.

## Composition

Use the following composition to build an `InputGroup`:

```text
InputGroup
├── InputGroupInput or InputGroupTextarea
├── InputGroupAddon
├── InputGroupButton
└── InputGroupText
```

## Parts

| Part               | Class                      | Data attribute                  |
| ------------------ | -------------------------- | ------------------------------- |
| InputGroup         | `np-input-group`           | `data-np-input-group`           |
| InputGroupAddon    | `np-input-group-addon`     | `data-np-input-group-addon`     |
| InputGroupText     | `np-input-group-text`      | `data-np-input-group-text`      |
| InputGroupButton   | `np-input-group-button`    | `data-np-input-group-button`    |
| InputGroupInput    | `np-input-group-input`     | `data-np-input-group-input`     |
| InputGroupTextarea | `np-input-group-textarea`  | `data-np-input-group-textarea`  |

## Align

Use `data-align` or the matching class on an addon to place it. Addons can be written in any order in your HTML. Their position follows the alignment.

| Position     | Data attribute             | Class alias                         |
| ------------ | -------------------------- | ----------------------------------- |
| Inline start | `data-align="inline-start"` | `np-input-group-addon` (default)   |
| Inline end   | `data-align="inline-end"`   | `np-input-group-addon-end`         |
| Block start  | `data-align="block-start"`  | `np-input-group-addon-block-start` |
| Block end    | `data-align="block-end"`    | `np-input-group-addon-block-end`   |

## Focus on click

In React, clicking an addon focuses the input. In plain HTML, add a small handler if you want the same behavior.

```html
<script>
  document.querySelectorAll(".np-input-group-addon").forEach((addon) => {
    addon.addEventListener("click", (event) => {
      if (event.target.closest("button")) return
      addon.parentElement.querySelector("input, textarea")?.focus()
    })
  })
</script>
```
