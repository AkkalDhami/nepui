## Installation

```bash
npx nepui@latest add button
```

---

## Usage

Use the `button` component in your project.

```html title="button.html" showLineNumbers {2} 
<html>
  <link rel="stylesheet" href="./styles/button.css">
</html>
```

```html title="button.html" showLineNumbers {2-8}
<body>
  <button
    type="button"
    class="np-button"
    data-variant="default"
  >
    Button
  </button>
</body>
```

---

## Variants

Use `data-variant` attribute or the matching class alias to choose a visual style. The default button can use `np-button`.

```html title="button.html" showLineNumbers
<button class="np-button" type="button">
  Default
</button>

<button class="np-button" type="button" data-variant="outline">
  Outline
</button>

<button class="np-button" type="button" data-variant="secondary">
  Secondary
</button>

<button class="np-button" type="button" data-variant="ghost">
  Ghost
</button>

<button class="np-button" type="button" data-variant="destructive">
  Destructive
</button>

<!-- Equivalent class aliases -->
<button class="np-button np-button-outline" type="button">
  Outline
</button>

<button class="np-button np-button-ghost" type="button">
  Ghost
</button>
```

Button variants can be specified using either `data-variant` attributes or their corresponding class aliases.

| Variant     | Data attribute               | Class alias             |
| ----------- | ---------------------------- | ----------------------- |
| Default     | `data-variant="default"`     | `np-button`             |
| Outline     | `data-variant="outline"`     | `np-button-outline`     |
| Secondary   | `data-variant="secondary"`   | `np-button-secondary`   |
| Ghost       | `data-variant="ghost"`       | `np-button-ghost`       |
| Destructive | `data-variant="destructive"` | `np-button-destructive` |

| Icon large       | `data-size="icon-lg"` | `np-button-icon-lg` |

## Icons

Buttons support inline SVG icons. Mark decorative icons as hidden and provide an accessible name for icon-only buttons.

```html title="button.html"
<button class="np-button" type="button" data-variant="outline">
  <svg aria-hidden="true" viewBox="0 0 24 24">...</svg>
  Continue
</button>
```


---

## Disabled

Use the native `disabled` attribute for unavailable actions.`.

```html title="button.html" showLineNumbers
<button class="np-button" type="button" disabled>
  Disabled
</button>
```

## Spinner

```html title="button.html" showLineNumbers
<button
  class="np-button"
  type="button"
  data-state="loading"
  aria-busy="true"
  disabled
>
  Loading...
</button>
```

> **Loading button: Use the [`spinner`](/docs/components/html/spinner) component when you want to display a spinner with text or other content inside the button.**

```html title="button.html" showLineNumbers {2}
<button data-np-button data-loading>
  <span data-np-spinner data-size="sm"></span>
  Loading...
</button>
```

## Forms

Always specify the button's `type` explicitly in forms.

```html title="button.html" showLineNumbers
<form>
  <button class="np-button" type="submit">
    Submit
  </button>

  <button class="np-button" type="reset" data-variant="outline">
    Reset
  </button>

  <button class="np-button" type="button" data-variant="ghost">
    Cancel
  </button>
</form>
```
