## Installation

```bash
npx nepui@latest add button
```

---

## Usage

Use the `button` component in your project.

```html title="button.html" showLineNumbers {2} 
<html>
  <link rel="stylesheet" href="./styles/button.css">
</html>
```

```html title="button.html" showLineNumbers {2-8}
<body>
  <button
    type="button"
    class="np-button"
    data-variant="default"
  >
    Button
  </button>
</body>
```

Button sizes can be specified using either `data-size` attributes or their corresponding class aliases.

| Size             | Data attribute        | Class alias         |
| ---------------- | --------------------- | ------------------- |
| Extra small      | `data-size="xs"`      | `np-button-xs`      |
| Small            | `data-size="sm"`      | `np-button-sm`      |
| Large            | `data-size="lg"`      | `np-button-lg`      |
| Icon extra small | `data-size="icon-xs"` | `np-button-icon-xs` |
| Icon small       | `data-size="icon-sm"` | `np-button-icon-sm` |
| Icon             | `data-size="icon"`    | `np-button-icon`    |
| Icon large       | `data-size="icon-lg"` | `np-button-icon-lg` |

## Variant

Use `data-variant` attribute or the matching class alias to choose a visual style. The default button can use `np-button`.

```html title="button.html" showLineNumbers
<button class="np-button" type="button">
  Default
</button>

<button class="np-button" type="button" data-variant="outline">
  Outline
</button>

<button class="np-button" type="button" data-variant="secondary">
  Secondary
</button>

<button class="np-button" type="button" data-variant="ghost">
  Ghost
</button>

<button class="np-button" type="button" data-variant="destructive">
  Destructive
</button>

<a
  class="np-button"
  href="https://github.com/akkaldhami/nepui"
  target="_blank"
  data-variant="link"
>
  Docs
</a>
```

Button variants can be specified using either `data-variant` attributes or their corresponding class aliases.

| Variant     | Data attribute               | Class alias             |
| ----------- | ---------------------------- | ----------------------- |
| Default     | `data-variant="default"`     | `np-button`             |
| Outline     | `data-variant="outline"`     | `np-button-outline`     |
| Secondary   | `data-variant="secondary"`   | `np-button-secondary`   |
| Ghost       | `data-variant="ghost"`       | `np-button-ghost`       |
| Destructive | `data-variant="destructive"` | `np-button-destructive` |
| Link | `data-variant="link"` | `np-button-link` |
