## Usage

Link the design tokens and the component's CSS file to your HTML document.

```html
<head>
  <link rel="stylesheet" href="./styles/tokens.css">
  <link rel="stylesheet" href="./styles/radio-group.css">
</head>
```

Use native radio inputs. Give the inputs in one group the same `name`.

```html showLineNumbers
<div class="np-radio-group" role="radiogroup" aria-label="Density">
  <input
    class="np-radio-group-item"
    type="radio"
    name="density"
    value="default"
    aria-label="Default"
  />
  <input
    class="np-radio-group-item"
    type="radio"
    name="density"
    value="comfortable"
    aria-label="Comfortable"
    checked
  />
  <input
    class="np-radio-group-item"
    type="radio"
    name="density"
    value="compact"
    aria-label="Compact"
  />
</div>
```

Or use the data attributes instead of classes:

```html showLineNumbers
<div data-np-radio-group role="radiogroup" aria-label="Density">
  <input
    data-np-radio-group-item
    type="radio"
    name="density"
    value="default"
    aria-label="Default"
  />
  <input
    data-np-radio-group-item
    type="radio"
    name="density"
    value="comfortable"
    aria-label="Comfortable"
    checked
  />
</div>
```

Keyboard support (arrow keys, `Tab`, `Space`) comes from the native inputs. Give every input a `<label for>` or an `aria-label`.

## Composition
Use the following composition to build a `RadioGroup`:

```text
RadioGroup
├── RadioGroupItem
└── RadioGroupItem
```

## Reference

### Group and item

| Name | Data attribute | Class alias |
| ---- | -------------- | ----------- |
| Radio group | `data-np-radio-group` | `np-radio-group` |
| Radio item | `data-np-radio-group-item` | `np-radio-group-item` |

### Orientation

| Name | Data attribute | Class alias |
| ---- | -------------- | ----------- |
| Vertical (default) | - | `np-radio-group` |
| Horizontal | `data-orientation="horizontal"` | `np-radio-group-horizontal` |

### States

| State | Selector |
| ----- | -------- |
| Checked | `:checked`, `[data-checked]`, `[aria-checked="true"]` |
| Disabled | `:disabled`, `[aria-disabled="true"]`, `[data-disabled]` |
| Invalid | `[aria-invalid="true"]`, `[data-invalid]` |
