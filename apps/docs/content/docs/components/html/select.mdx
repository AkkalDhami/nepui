## Usage

Link the stylesheet:

```html
<link rel="stylesheet" href="./styles/select.css">
```

Put a `<select class="np-select">` inside a `np-select-wrapper`. The wrapper draws the chevron.

```html
<div class="np-select-wrapper">
  <select class="np-select" aria-label="Fruit">
    <option value="apple">Apple</option>
    <option value="banana">Banana</option>
  </select>
</div>
```

Or use the data attributes instead of classes:

```html
<div data-np-select-wrapper>
  <select data-np-select aria-label="Fruit">
    <option value="apple">Apple</option>
    <option value="banana">Banana</option>
  </select>
</div>
```

The wrapper is as wide as the select. Set a width on the `<select>` (for example `style="width: 12rem"`) to change it.

## Icons

Add `np-select-rich` (or `data-rich`) to put icons or other markup inside options. Write a `<button><selectedcontent></selectedcontent></button>` as the first child of the `<select>`: it shows the selected option, icon included.

<ComponentPreview
  name="select-icons"
  target="html"
  styles={["/select/select.css"]}
/>

This uses the browser's customizable select (`appearance: base-select`), which needs no JavaScript but is only available in Chrome and Edge 135+. Other browsers ignore the `<button>` and the icons and show a plain select with text-only options.

## Invalid

Wrap the select in a [Field](/docs/components/html/field). Add the `data-invalid` attribute to the field and `aria-invalid="true"` to the `<select>` to show an error state, and link the message with `aria-describedby`.
 
This example uses the Field styles, so link `field.css` before `select.css`:
 
```html
<link rel="stylesheet" href="./styles/field.css">
<link rel="stylesheet" href="./styles/select.css">
```

```html showLineNumbers /data-invalid/ /aria-invalid="true"/
<div class="np-field" data-invalid>
  <label class="np-field-label">Fruit</label>
  <select
    class="np-select"
    aria-invalid="true"
  >
    ...
  </select>
  <p class="np-field-error">Please select a fruit.</p>
</div>
```

<ComponentPreview
  name="select-invalid"
  target="html"
  styles={["/field/field.css"]}
/>

Without Field, set `aria-invalid="true"` (or `data-invalid`) on the `<select>` and show your own message. Only the select needs `select.css`.
