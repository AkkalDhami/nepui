## Usage

Link the stylesheet, and add the script once near the end of the page:

```html
<link rel="stylesheet" href="./styles/otp-field.css">
<script src="./javascripts/otp-field.js" defer></script>
```

Put one native input in each slot:

```html
<label class="np-label" id="code-label" for="code">Verification code</label>
<div class="np-otp-field" role="group" aria-labelledby="code-label">
  <input class="np-otp-field-input" id="code" type="text" inputmode="numeric" maxlength="1" autocomplete="one-time-code">
  <input class="np-otp-field-input" type="text" inputmode="numeric" maxlength="1" aria-label="Character 2 of 6">
  <input class="np-otp-field-input" type="text" inputmode="numeric" maxlength="1" aria-label="Character 3 of 6">
  <div class="np-otp-field-separator"></div>
  <input class="np-otp-field-input" type="text" inputmode="numeric" maxlength="1" aria-label="Character 4 of 6">
  <input class="np-otp-field-input" type="text" inputmode="numeric" maxlength="1" aria-label="Character 5 of 6">
  <input class="np-otp-field-input" type="text" inputmode="numeric" maxlength="1" aria-label="Character 6 of 6">
</div>
```

Or use the data attributes instead of classes: `data-np-otp-field`, `data-np-otp-field-input` and `data-np-otp-field-separator`.

The first slot uses the visible label, and every other slot needs its own `aria-label`. Use `autocomplete="one-time-code"` on the first slot so phones can fill the code.

Link the stylesheet:

```html
<link rel="stylesheet" href="./styles/field.css">
```

## Invalid

Add `data-invalid` to the `np-field` element and `aria-invalid` to each slot to show an error state.

```html /data-invalid/ /aria-invalid/
<div class="np-field" data-invalid>
  <label class="np-field-label" for="otp-invalid">Verification code</label>
  <div class="np-otp-field" role="group" aria-labelledby="otp-invalid-label">
    <input
      class="np-otp-field-input"
      type="text"
      inputmode="numeric"
      maxlength="1"
      value="6"
      aria-invalid
      autocomplete="one-time-code"
      id="otp-invalid"
    />
    ...
  </div>
</div>
```

## Reference

### Parts

| Name | Data attribute | Class alias |
| ---- | -------------- | ----------- |
| OTP field | `data-np-otp-field` | `np-otp-field` |
| Slot (`<input>`) | `data-np-otp-field-input` | `np-otp-field-input` |
| Separator | `data-np-otp-field-separator` | `np-otp-field-separator` |

### Size

| Name | Data attribute | Class alias |
| ---- | -------------- | ----------- |
| Small | `data-size="sm"` | `np-otp-field-sm` |
| Default | - | `np-otp-field` |
| Large | `data-size="lg"` | `np-otp-field-lg` |

### States

| State | Selector |
| ----- | -------- |
| Disabled | `:disabled`, `[aria-disabled="true"]`, `[data-disabled]` |
| Invalid | `[aria-invalid="true"]`, `[data-invalid]` |

### Script

The slots are plain inputs, so the script adds the behavior a one-time code needs:

- Typing a character moves focus to the next slot.
- Backspace on an empty slot clears the one before it. Arrow keys, `Home` and `End` move between slots.
- Pasting or autofilling a code fills the slots from the current one.
- Characters that do not match `data-validation` are rejected.
- It removes `maxlength` so that autofill can write a whole code. Keep `maxlength="1"` in the markup as a fallback when the script does not run.

Without the script each box is a separate input: the slots still render and can be typed into, but focus does not move on its own.

Add these data attributes to the `np-otp-field` element:

| Attribute | What it does |
| --------- | ------------ |
| `data-validation="numeric \| alpha \| alphanumeric \| none"` | Which characters are accepted. Defaults to `numeric`. |
| `data-uppercase` | Convert letters to uppercase. |
| `data-auto-submit` | Submit the form when every slot is filled. |

The script keeps the whole code in a hidden input if you add one inside the field, so a form can submit one value:

```html
<form>
  <div class="np-otp-field" data-auto-submit>
    <input type="hidden" name="code">
    <input class="np-otp-field-input" ...>
    ...
  </div>
</form>
```

When every slot is filled, the field fires a bubbling `np-otp-complete` event with the code in `event.detail.value`:

```js
document.addEventListener("np-otp-complete", (event) => {
  console.log(event.detail.value)
})
```
