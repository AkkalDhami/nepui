## Usage

Link the tokens and the stylesheet:

```html
<link rel="stylesheet" href="./styles/tokens.css">
<link rel="stylesheet" href="./styles/avatar.css">
```

Add the classes:

```html
<span class="np-avatar">
  <img class="np-avatar-image" src="https://github.com/akkaldhami.png" alt="@akkaldhami" onerror="this.hidden = true">
  <span class="np-avatar-fallback">CN</span>
</span>
```

Or use the data attributes instead of the classes:

```html
<span data-np-avatar>
  <img data-np-avatar-image src="https://github.com/akkaldhami.png" alt="@akkaldhami" onerror="this.hidden = true">
  <span data-np-avatar-fallback>CN</span>
</span>
```

## Composition

Use the following composition to build an `Avatar`:

```text
Avatar
├── AvatarImage
├── AvatarFallback
└── AvatarBadge
```

Use the following composition to build an `AvatarGroup`:

```text
AvatarGroup
├── Avatar
│   ├── AvatarImage
│   ├── AvatarFallback
│   └── AvatarBadge
├── Avatar
│   ├── AvatarImage
│   ├── AvatarFallback
│   └── AvatarBadge
└── AvatarGroupCount
```

---

## Image and fallback

With no JavaScript, the image and the fallback are stacked in the same spot and the image sits on top. While the image loads, the fallback shows through. 

If the image fails to load, `onerror="this.hidden = true"` hides it so the fallback stays visible. Without that attribute a broken image would cover the fallback. Leave out the `img` for a fallback-only avatar.
