## Usage

Link the component's CSS file to your HTML document, along with [Button](/docs/components/html/button) for the trigger.

```html
<head>
  <link rel="stylesheet" href="./styles/tokens.css">
  <link rel="stylesheet" href="./styles/button.css">
  <link rel="stylesheet" href="./styles/menu.css">
</head>
```

The HTML menu uses the browser's native [Popover API](https://developer.mozilla.org/docs/Web/API/Popover_API) to open and close, and CSS anchor positioning to sit under its trigger. You need no JavaScript to open it, close it with `Escape`, or close it by clicking outside.

```html
<div class="np-menu" style="--np-menu-anchor: --account">
  <button class="np-button np-button-outline" type="button" popovertarget="account">
    Open
  </button>

  <div id="account" class="np-menu-content" popover role="menu" aria-label="My Account">
    <button class="np-menu-item" type="button" role="menuitem">Profile</button>
    <button class="np-menu-item" type="button" role="menuitem">Billing</button>
    <div class="np-menu-separator" role="separator"></div>
    <button class="np-menu-item" type="button" role="menuitem">Log out</button>
  </div>
</div>
```

Every part also works with a `data-np-*` attribute instead of the class, for example `data-np-menu-content` and `data-np-menu-item`.

---

## Anchoring

The wrapper (`np-menu`) carries one `--np-menu-anchor` name. It links the trigger and the popup, so you need a **unique dashed name for each menu** on the page.

```html
<div class="np-menu" style="--np-menu-anchor: --account"> ... </div>
<div class="np-menu" style="--np-menu-anchor: --actions"> ... </div>
```

Use the `--np-menu-offset` variable to change the gap to the trigger (default `0.25rem`). In browsers without anchor positioning, the popup opens next to the trigger instead of under it.

## Closing on click

Clicking outside or pressing `Escape` closes the menu. To close it when an item is chosen, make the item a hide button for the popup:

```html
<button
  class="np-menu-item"
  type="button"
  role="menuitem"
  popovertarget="account"
  popovertargetaction="hide"
>
  Profile
</button>
```

Checkbox and radio items stay open, so they don't need it.

## Checkboxes

Use `role="menuitemcheckbox"` and `aria-checked`. The check mark is shown only when `aria-checked` is not `"false"`. Toggle the attribute yourself.

<ComponentPreview
  name="menu-checkboxes"
  target="html"
  styles={["/button/button.css"]}
  scripts={["/menu/menu.js"]}
/>

```html
<button
  class="np-menu-item np-menu-checkbox-item"
  type="button"
  role="menuitemcheckbox"
  aria-checked="true"
  onclick="this.setAttribute('aria-checked', this.getAttribute('aria-checked') !== 'true')"
>
  <span class="np-menu-item-indicator"><!-- check icon --></span>
  Status Bar
</button>
```

## Keyboard navigation

The native popover gives you `Escape`, outside click and focus return. Arrow-key navigation is not built in. Add this small script if you want it, or use the [React version](/docs/components/react/menu), which is built on Base UI and handles it fully, including typeahead and submenus.

```html
<script>
  // Focus the first item when a menu opens
  document.addEventListener(
    "toggle",
    (event) => {
      if (event.newState === "open" && event.target.matches('[role="menu"]')) {
        event.target.querySelector('[role^="menuitem"]:not(:disabled)')?.focus()
      }
    },
    true
  )

  // Arrow keys, Home and End move between the items of the open menu
  document.addEventListener("keydown", (event) => {
    const menu = event.target.closest('[role="menu"]')
    if (!menu) return

    const items = [...menu.querySelectorAll('[role^="menuitem"]:not(:disabled)')].filter(
      (item) => item.closest('[role="menu"]') === menu
    )
    const index = items.indexOf(document.activeElement)
    let next

    if (event.key === "ArrowDown") next = items[(index + 1) % items.length]
    else if (event.key === "ArrowUp") next = items[(index - 1 + items.length) % items.length]
    else if (event.key === "Home") next = items[0]
    else if (event.key === "End") next = items[items.length - 1]

    if (next) {
      event.preventDefault()
      next.focus()
    }
  })
</script>
```
