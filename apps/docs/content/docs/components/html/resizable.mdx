## Usage

Link the stylesheet, after `tokens.css`, and the optional script:

```html 
<link rel="stylesheet" href="./styles/resizable.css">

<script src="./scripts/resizable.js" defer></script>
```

```html 
<div class="np-resizable" style="height: 12.5rem">
  <div class="np-resizable-panel" data-default-size="50">One</div>
  <div class="np-resizable-handle" role="separator" tabindex="0" aria-label="Resize">
    <div class="np-resizable-grip"></div>
  </div>
  <div class="np-resizable-panel" data-default-size="50">Two</div>
</div>
```

Or use the data attributes instead of classes: `data-np-resizable`, `data-np-resizable-panel`, `data-np-resizable-handle`, `data-np-resizable-grip`.

The group is a flex container that fills its parent, so give the group (or its parent) a height. `data-default-size` is the starting share of the group, so `25` and `75` make a quarter and three quarters (`"25%"` works too). The numbers need not add up to 100. A panel without it gets a share of 1, so panels without it share equally. Colours come from tokens, so dark mode needs no extra setup.

The sizes come from `data-default-size`, and the layout works with no JavaScript in browsers that support typed `attr()` (Chrome 133 and later). In the others, `resizable.js` applies the sizes when the page loads. It also adds the drag and the keyboard.

## Limits

Set `data-min-size` and `data-max-size` (a percent of the group) on a panel, next to `data-default-size`. The default is 0 to 100, so a panel can collapse to nothing. The sidebar here stays between 15% and 40%, and the content keeps at least 60%.

## Reference

### Keyboard

Focus a handle (Tab) and use:

| Key | Effect |
| --- | --- |
| Arrow Left / Right | Move the handle (Up / Down in a vertical group). |
| Home / End | Move it as far as the two panels allow. |

`data-step` on a handle sets the percent moved per key press (default `10`). A handle with `data-disabled` or `aria-disabled="true"` cannot be moved.

---

### Script

`resizable.js` has no dependencies and starts itself. It:

- adds `role="separator"`, `tabindex="0"` and the `aria-value*` attributes to each handle, unless you wrote them,
- sets up groups that are added after the page loaded,
- sets `data-dragging` on the handle and `data-resizing` on the group while dragging,
- keeps the sizes adding up to 100, and
- fires `np-resizable-change` on the group, with `detail.sizes` in percent.

```js
group.addEventListener("np-resizable-change", (event) => {
  console.log(event.detail.sizes) // [25, 75]
})
```

For a group added later, call `NepuiResizable.init(group)`.

---

### Not in HTML

There are no collapsible panels, no saved layouts and no panel sizes in pixels. Use the React version for those.
