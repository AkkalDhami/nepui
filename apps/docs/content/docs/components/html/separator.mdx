## Usage

Link the design tokens and the component's CSS file to your HTML document.

```html
<head>
  <link rel="stylesheet" href="./styles/tokens.css">
  <link rel="stylesheet" href="./styles/separator.css">
</head>
```

Then, add the `np-separator` class to an element and give it `role="separator"`.

```html
<div class="np-separator" role="separator"></div>
```

You can also use the `data-np-separator` attribute instead of the class.

```html
<div data-np-separator role="separator"></div>
```

For a purely decorative line, use `aria-hidden="true"` instead of `role="separator"`. A native `<hr>` already has the separator role.

```html
<hr class="np-separator" />
```

## Class and data attributes

Use classes or data attributes on any element, including `<hr>`.

```html
<div class="np-separator" role="separator"></div>

<div data-np-separator data-orientation="vertical" role="separator"></div>
```

| Part       | Class                    | Data attribute                |
| ---------- | ------------------------ | ----------------------------- |
| Separator  | `np-separator`           | `data-np-separator`           |
| Vertical   | `np-separator-vertical`  | `data-orientation="vertical"` |
