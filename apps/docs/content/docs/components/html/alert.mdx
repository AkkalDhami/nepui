## Usage

Link the tokens and the stylesheet:

```html
<link rel="stylesheet" href="./styles/tokens.css">
<link rel="stylesheet" href="./styles/alert.css">
```

Add the classes. A direct `svg` child becomes the icon:

```html
<div class="np-alert" role="alert">
  <svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round" aria-hidden="true">
    <circle cx="12" cy="12" r="10" /><path d="M12 16v-4" /><path d="M12 8h.01" />
  </svg>
  <div class="np-alert-title">Heads up!</div>
  <div class="np-alert-description">You can add components to your app using the CLI.</div>
</div>
```

Or use the data attributes instead of the classes:

```html
<div data-np-alert role="alert">
  <div data-np-alert-title>Heads up!</div>
  <div data-np-alert-description>You can add components to your app using the CLI.</div>
</div>
```

## Action

Add `np-alert-action` to pin a button to the top end corner. The alert reserves space for it. This example needs the Button stylesheet, so link `button.css` first (see [Button](/docs/components/html/button)).

<link rel="stylesheet" href="./styles/button.css">

## Reference

### Component

| Name | Data attribute | Class alias |
| ---- | -------------- | ----------- |
| Alert | `data-np-alert` | `np-alert` |
| Title | `data-np-alert-title` | `np-alert-title` |
| Description | `data-np-alert-description` | `np-alert-description` |
| Action | `data-np-alert-action` | `np-alert-action` |

### Variant

| Name | Data attribute | Class alias |
| ---- | -------------- | ----------- |
| Default | - | - |
| Success | `data-variant="success"` | `np-alert-success` |
| Info | `data-variant="info"` | `np-alert-info` |
| Warning | `data-variant="warning"` | `np-alert-warning` |
| Error | `data-variant="error"` | `np-alert-error` |
