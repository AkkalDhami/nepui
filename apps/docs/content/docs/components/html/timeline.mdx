## Usage

Link the stylesheet, after `tokens.css`, and the script at the end of the page. The script is optional, and the timeline looks the same without it:

```html
<link rel="stylesheet" href="./styles/timeline.css">

<script src="./javascripts/timeline.js" defer></script>
```

```html
<div class="np-timeline" aria-label="Activity">
  <div class="np-timeline-item">
    <span class="np-timeline-marker"></span>
    <span class="np-timeline-connector"></span>
    <div class="np-timeline-title">Deployed to production</div>
    <time class="np-timeline-time" datetime="2026-11-14T10:42">10:42</time>
    <div class="np-timeline-description">Version 2.4.0 is live.</div>
  </div>
</div>
```

Or use the data attributes instead of classes: `data-np-timeline`, `data-np-timeline-item`, `data-np-timeline-marker`, `data-np-timeline-connector`, `data-np-timeline-title`, `data-np-timeline-time` and `data-np-timeline-description`.

The items must be direct children of the timeline. Every part inside an item is optional.

The script adds the list and listitem roles, names each event from its title and describes it from its time and description, marks the current event with `aria-current="step"`, and gives the list one tab stop with the keys below. Status shown only by the marker is not visible to screen readers, so also say it in the title or the description, such as "Shipped, in progress".

## Status

Give the timeline a `data-value`, the number of finished steps, and every item a `data-step`. Items up to `value` are complete, the next one is current, and the rest are upcoming. Use `data-status` on an item to set it yourself. The current item gets `aria-current="step"`, and it takes the tab stop first.

## Keyboard

| Key | Behavior |
| --- | --- |
| Tab | Enters the timeline on the current event, or the last one you focused, or the first. |
| Arrow Down, Arrow Up | Move between events (vertical). |
| Arrow Right, Arrow Left | Move between events (horizontal). They swap in RTL. |
| Home, End | Go to the first or the last event. |
| Page Down, Page Up | Next or previous article (feed only). |

Arrow keys act only on the event itself, so controls inside an event keep them. They stop at the ends unless `data-loop` is set.

## Reference

### Options

| Where | Attribute | Description |
| --- | --- | --- |
| Timeline | `data-orientation="horizontal"` | Lays the events in a row. `np-timeline-horizontal` does the same. |
| Timeline | `data-value` | The number of finished steps. |
| Timeline | `data-feed` | Makes the list a feed. |
| Timeline | `data-busy` | Sets `aria-busy` while a feed loads. |
| Timeline | `data-loop` | Wraps the arrow keys from the last event to the first. |
| Item | `data-step` | The position of the event. Used with the timeline's `data-value`. |
| Item | `data-status` | `complete`, `current` or `upcoming`. Overrides the status taken from `data-step`. |
| Item | `data-value` | Names the event for `NepuiTimeline.get(element).focus(value)`. |

The script sets `data-complete`, `data-current` and `data-upcoming` on the item and on its marker and connector, and the CSS variables `--np-timeline-count` and `--np-timeline-index`. It also watches the timeline, so events you add later are wired, and changes to `data-value` and `data-busy` are picked up.

### Script

```html
<script src="./javascripts/timeline.js" defer></script>
```

| API | Description |
| --- | --- |
| `NepuiTimeline.init(element)` | Wires one timeline. Use it for a timeline added after the page loaded. |
| `NepuiTimeline.initAll(scope?)` | Wires every timeline in the scope, or on the page. |
| `NepuiTimeline.get(element)` | Returns `{ focus, refresh }`. `focus(value?)` moves focus to the event with that `data-value`, or to the one that holds the tab stop. |
