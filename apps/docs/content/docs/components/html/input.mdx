## Usage

Link the component's CSS file to your HTML document.

```html
<head>
  <link rel="stylesheet" href="./styles/input.css">
</head>
```

Then add the `data-np-input` attribute or `np-input` class to your `<input>` element.
```html
<input
  name="name"
  placeholder="Enter your name"
  class="np-input"
  data-size="sm"
/>
<input name="email" placeholder="Enter your email" data-np-input />
<input
  id="password"
  name="password"
  placeholder="Enter your password"
  class="np-input"
  data-size="lg"
/>
```

## Size

Use `data-size` attribute or a matching class alias to change the size of the input.

<ComponentPreview
  name="input-size"
  target="html"
/>

| Size             | Data attribute        | Class alias         |
| ---------------- | --------------------- | ------------------- |
| Extra small      | `data-size="xs"`      | `np-input-xs`      |
| Small            | `data-size="sm"`      | `np-input-sm`      |
| Large            | `data-size="lg"`      | `np-input-lg`      |
