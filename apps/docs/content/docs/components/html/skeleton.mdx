## Usage

Link the design tokens and the component's CSS file to your HTML document.

```html
<head>
  <link rel="stylesheet" href="./styles/tokens.css">
  <link rel="stylesheet" href="./styles/skeleton.css">
</head>
```

Then, add the `np-skeleton` class to an element and set its size.

```html
<div class="np-skeleton" style="width: 12rem"></div>
```

You can also use the `data-np-skeleton` attribute instead of the class.
 
```html
<div data-np-skeleton style="width: 12rem"></div>
```

## Class and data attributes

Use classes or data attributes on any element.

```html
<div class="np-skeleton" style="width: 12rem"></div>

<div data-np-skeleton data-shape="circle" style="width: 3rem; height: 3rem"></div>
```

| Part     | Class                | Data attribute          |
| -------- | -------------------- | ----------------------- |
| Skeleton | `np-skeleton`        | `data-np-skeleton`      |
| Circle   | `np-skeleton-circle` | `data-shape="circle"`   |
