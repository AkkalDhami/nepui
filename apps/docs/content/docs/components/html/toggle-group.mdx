## Usage

Load `toggle.css` first, then `toggle-group.css`.

```html
<link rel="stylesheet" href="./styles/toggle.css" />
<link rel="stylesheet" href="./styles/toggle-group.css" />

<script src="./javascripts/toggle-group.js" defer></script>
```

```html
<div class="np-toggle-group" role="group" aria-label="Text formatting">
  <button type="button" class="np-toggle" aria-pressed="false" aria-label="Toggle bold">Bold</button>
  <button type="button" class="np-toggle" aria-pressed="false" aria-label="Toggle italic">Italic</button>
</div>
```

Or use the data attributes instead of the classes:

```html
<div data-np-toggle-group role="group" aria-label="Text formatting">
  <button type="button" data-np-toggle aria-pressed="false" aria-label="Toggle bold">Bold</button>
  <button type="button" data-np-toggle aria-pressed="false" aria-label="Toggle italic">Italic</button>
</div>
```

Items are plain `np-toggle` buttons placed directly inside the group. Variant and size go on the group, not on each item. Give the group a `role="group"` and an `aria-label`, and give icon-only items their own `aria-label`.

## Reference

### Variants

| Name    | Data attribute           | Class alias                 |
| ------- | ------------------------ | --------------------------- |
| Default | -                        | `np-toggle-group`           |
| Outline | `data-variant="outline"` | `np-toggle-group-outline`   |

### Sizes

| Name    | Data attribute   | Class alias             |
| ------- | ---------------- | ----------------------- |
| Small   | `data-size="sm"` | `np-toggle-group-sm`    |
| Default | -                | `np-toggle-group`       |
| Large   | `data-size="lg"` | `np-toggle-group-lg`    |

### Orientation

| Name       | Data attribute               | Class alias                 |
| ---------- | ---------------------------- | --------------------------- |
| Horizontal | -                            | `np-toggle-group`           |
| Vertical   | `data-orientation="vertical"` | `np-toggle-group-vertical` |

### Spacing

| Name      | Data attribute    | Class alias                  |
| --------- | ----------------- | ---------------------------- |
| Default   | -                 | `np-toggle-group`            |
| Connected | `data-spacing="0"` | `np-toggle-group-connected` |

### Behavior

These are read by `toggle-group.js`, the stylesheet ignores them.

| Name     | Data attribute  | Class alias                  |
| -------- | --------------- | ---------------------------- |
| Single   | -               | `np-toggle-group`            |
| Multiple | `data-multiple` | `np-toggle-group-multiple`   |

### Parts

| Name  | Data attribute  | Class alias                               |
| ----- | --------------- | ----------------------------------------- |
| Group | `data-np-toggle-group` | `np-toggle-group`                  |
| Item  | `data-np-toggle`       | `np-toggle` (direct child of the group) |

### States

| State          | Selector                                   |
| -------------- | ------------------------------------------ |
| Disabled group | `[data-disabled]`, `[aria-disabled="true"]` |

Item states (`aria-pressed`, `disabled`, `aria-invalid`) are described in [Toggle](/docs/components/html/toggle).
