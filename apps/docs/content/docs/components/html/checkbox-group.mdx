## Usage

Link the stylesheets:

```html
<link rel="stylesheet" href="./styles/tokens.css">
<link rel="stylesheet" href="./styles/label.css">
<link rel="stylesheet" href="./styles/checkbox.css">
<link rel="stylesheet" href="./styles/checkbox-group.css">
```

Add the class to a wrapper and put labeled checkboxes inside:

```html
<div class="np-checkbox-group" role="group" aria-label="Select frameworks">
  <label class="np-label"><input class="np-checkbox" type="checkbox" value="next" checked>Next.js</label>
  <label class="np-label"><input class="np-checkbox" type="checkbox" value="vite">Vite</label>
  <label class="np-label"><input class="np-checkbox" type="checkbox" value="astro">Astro</label>
</div>
```

Or use the data attribute instead of the class:

```html
<div data-np-checkbox-group role="group" aria-label="Select frameworks">
  <!-- labeled checkboxes -->
</div>
```
