## Usage

Link the stylesheet:

```html
<link rel="stylesheet" href="./styles/aspect-ratio.css">
```

The default ratio is 16 / 9. Put an `img`, `video` or `iframe` directly inside and it fills the box:

```html
<div class="np-aspect-ratio" style="max-width: 24rem">
  <img src="..." alt="Image" style="border-radius: var(--np-radius-md)">
</div>
```

Or use the data attribute instead of the class:

```html
<div data-np-aspect-ratio style="max-width: 24rem">
  <img src="..." alt="Image">
</div>
```

For any other ratio, set `--np-aspect-ratio-value`:

```html
<div class="np-aspect-ratio" style="--np-aspect-ratio-value: 3 / 2">
  <img src="..." alt="Image">
</div>
```

Direct `img`, `video` and `iframe` children are cropped with `object-fit: cover`. Set `--np-aspect-ratio-fit: contain` to show the whole image. Give any other child `height: 100%` if it should fill the box too.

## Custom ratio

Set `--np-aspect-ratio-value` on the element for any other ratio. This example uses a 21 / 9 ultrawide ratio with `style="--np-aspect-ratio-value: 21 / 9"`. A plain number such as `2.33` works too.
