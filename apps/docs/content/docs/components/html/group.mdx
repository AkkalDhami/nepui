## Usage

Link the stylesheet, after `tokens.css`:

```html
<link rel="stylesheet" href="./styles/group.css">
```

```html
<div class="np-group" role="group" aria-label="File actions">
  <button type="button" class="np-button np-button-outline">Files</button>
  <div class="np-group-separator" role="separator" aria-orientation="vertical"></div>
  <button type="button" class="np-button np-button-outline">Media</button>
</div>
```

Or use the data attributes instead of classes: `data-np-group`, `data-np-group-text`, `data-np-group-separator`.

The direct children of the group are the controls. Their inner corners and the border between them are removed. A control should draw its own border and radius, as the nepui button, input and select do. A control followed by a separator drops its end border, so the divider is not doubled. Without a separator, the neighbours share one border.

Give the group a name with `aria-label` or `aria-labelledby`. Use a group for controls that do something. For controls that toggle, use a toggle group. Colours come from tokens, so dark mode needs no extra setup. The styles use `:has()` and `color-mix()`, which need a modern browser.

## Accessibility

- The group has `role="group"`. Name it with `aria-label` or `aria-labelledby`.
- Tab moves between the controls, in order.
- The separator is decoration. It takes no focus.

## Reference
### Parts

| Name | Data attribute | Class alias |
| --- | --- | --- |
| Root | `data-np-group` | `np-group` |
| Text | `data-np-group-text` | `np-group-text` |
| Separator | `data-np-group-separator` | `np-group-separator` |

### Options

| Where | Option | Class alias | Data attribute |
| --- | --- | --- | --- |
| Root | Vertical | `np-group-vertical` | `data-orientation="vertical"` |
| Separator | Horizontal line | `np-group-separator-horizontal` | `data-orientation="horizontal"` |

### State

| Name | Effect |
| --- | --- |
| A control has focus | It rises above its neighbours, so its ring is whole. |
| A separator is next to a focused control | It takes the ring colour. |
