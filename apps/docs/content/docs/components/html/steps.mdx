## Usage

Link the component's CSS file to your HTML document.

```html
<head>
  <link rel="stylesheet" href="./styles/steps.css">
</head>
```

Then add the `data-np-steps` attribute or `np-steps` class to your `<div>` element.

Add the `data-np-step` attribute or `np-step` class to each `<h3>` element to create a step indicator.

```html
<div data-np-steps>
  <h3 class="np-step">Create your component structure.</h3>

  <h3 data-np-step>Add the required HTML and CSS.</h3>

  <h3 class="np-step">Import nepui&apos;s design tokens.</h3>

  <h3 data-np-step>Add the component behavior.</h3>
  
  <h3 class="np-step">Customize the component with CSS variables.</h3>
</div>
```
