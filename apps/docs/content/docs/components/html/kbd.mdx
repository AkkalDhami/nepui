## Usage

Link the component's CSS file to your HTML document.

```html
<head>
  <link rel="stylesheet" href="./styles/kbd.css">
</head>
```

Then, add the `np-kbd` class to a `<kbd>` element.

```html
<kbd class="np-kbd">Esc</kbd>
```

You can also use the `data-np-kbd` attribute instead of the class.

```html
<kbd data-np-kbd>Esc</kbd>
```

Use the native `<kbd>` element so assistive technologies announce it as keyboard input.

## Group

Use `np-kbd-group` or `data-np-kbd-group` to group keys together into one shortcut.

<ComponentPreview
  name="kbd-group"
  target="html"
/>

```html
<kbd class="np-kbd-group">
  <kbd class="np-kbd">Ctrl</kbd>
  <kbd class="np-kbd">K</kbd>
</kbd>
```

The group is a `<kbd>` that wraps the keys. Nesting `<kbd>` elements is the recommended markup for key combinations.

## Tooltip

Inside an element with `data-slot="tooltip-content"` (or the `np-tooltip-content` class), keys switch to a translucent background and the tooltip's text color, so they stay readable on the tooltip's inverted surface.

```html
<div data-slot="tooltip-content">
  Open the command palette <kbd class="np-kbd">⌘K</kbd>
</div>
```
