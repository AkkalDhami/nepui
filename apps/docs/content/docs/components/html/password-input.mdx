## Usage

Add the stylesheet next to the design tokens, and the script after your markup:

```html
<link rel="stylesheet" href="./styles/tokens.css">
<link rel="stylesheet" href="./styles/password-input.css">
<link rel="stylesheet" href="./styles/field.css">

<script src="./javascripts/password-input.js"></script>
```

Use a native `<input type="password">` and a toggle button inside the root. The script finds them, so there is no inline JavaScript to write.

```html
<div class="np-password-input">
  <input class="np-password-input-control" id="password" type="password"
    autocomplete="current-password" spellcheck="false" autocapitalize="off" />
  <button class="np-password-input-toggle" type="button"
    aria-label="Show password" aria-pressed="false">
    <svg class="np-password-input-icon-show" ...><!-- eye --></svg>
    <svg class="np-password-input-icon-hide" ...><!-- eye off --></svg>
  </button>
</div>
```

The toggle holds both eye icons, and CSS shows one of them from `aria-pressed`. The script adds `aria-controls` for you. Or use data attributes instead of classes:

```html
<div data-np-password-input>
  <input data-np-password-input-control id="password" type="password" … />
  <button data-np-password-input-toggle type="button" aria-label="Show password" aria-pressed="false">…</button>
</div>
```

Put it in a [Field](/docs/components/html/field) with a `<label for>` so it gets a label and a description. Link the stylesheet:

```html
<link rel="stylesheet" href="./styles/field.css">
```

#### What the script does

- Shows and hides the password from the toggle, and keeps the caret and selection. A pointer press from elsewhere brings focus back to the input. A keyboard press keeps focus on the toggle.
- Hides a shown password again when its form is submitted or reset, and when the page is hidden.
- Sets `data-capslock` on the root while Caps Lock is on and the input has focus. The chip shows from CSS.
- Keeps the strength meter and the requirements checklist in step with the value.
- Runs the actions: `data-action="copy"`, `"clear"` and `"generate"`.
- Initialises roots that are added to the page later too.

> **Note:** Without the script the field is a normal password input, and the toggle does nothing. Load the script, or leave the toggle out. Add `autocomplete="new-password"` when creating a password.

## Composition

Use the following structure to build a password field. Each part also has a class alias:

```text
[data-np-password-input] / .np-password-input
├── [data-np-password-input-addon] / .np-password-input-addon      (optional, before or after the control)
├── [data-np-password-input-control] / .np-password-input-control
├── [data-np-password-input-caps-lock] / .np-password-input-caps-lock   (optional)
├── [data-np-password-input-action] / .np-password-input-action      (optional, any number)
├── [data-np-password-input-toggle] / .np-password-input-toggle
└── [data-np-password-input-strength] / .np-password-input-strength    (optional, after the field)

[data-np-password-input-requirements] / .np-password-input-requirements   (optional, after the field)
└── [data-rule] / li[data-rule]
```

The root holds the value and the toggled visibility state, and it draws the field box. Put `name`, `form`, `required`, `disabled`, `readonly` and `autocomplete` on the root. Put other native input attributes, such as `placeholder`, on the control.

The strength meter and the checklist sit outside the box, as siblings after the root.

## Strength meter

Put the meter in the same field as the input, after the root. The script scores the value from 0 to 4 and sets `data-level`, `aria-valuenow`, `aria-valuetext` and the label text.

<ComponentPreview
  target="html"
  name="password-input-strength"
  styles={["/field/field.css"]}
  scripts={["/password-input/password-input.js"]}
/>

```html
<div class="np-password-input-strength" role="meter" aria-label="Password strength"
  aria-valuemin="0" aria-valuemax="4" aria-valuenow="0" aria-valuetext="Enter a password" data-level="0">
  <div class="np-password-input-strength-bars" aria-hidden="true">
    <span class="np-password-input-strength-bar"></span>
    <span class="np-password-input-strength-bar"></span>
    <span class="np-password-input-strength-bar"></span>
    <span class="np-password-input-strength-bar"></span>
  </div>
  <span class="np-password-input-strength-label">Enter a password</span>
</div>
```

The default score counts four checks: 8 or more characters, a digit, upper and lower case, and a symbol. A non-empty password scores at least 1. To rename the labels, set `data-labels="Empty|Weak|Fair|Good|Strong"` on the meter. To score your own way, replace the function before or after the script loads:

```js
NepuiPasswordInput.score = (value) => (value.length >= 12 ? 4 : 1)
```

## Requirements

Give each `li` a `data-rule`. The script sets `data-met` on the ones that pass. The `li` holds both icons and both status texts, and CSS shows the right ones.

<ComponentPreview
  target="html"
  name="password-input-requirements"
  styles={["/field/field.css"]}
  scripts={["/password-input/password-input.js"]}
/>

| Rule | Passes when |
| ---- | ----------- |
| `data-rule="length"` | The value has at least `data-min` characters (default 8). |
| `data-rule="number"` | It has a digit. |
| `data-rule="letter"` | It has a letter. |
| `data-rule="case"` | It has an uppercase and a lowercase letter. |
| `data-rule="symbol"` | It has a character that is not a letter or a digit. |
| `data-pattern="<regex>"` | It matches your regular expression. |

## Actions

Add a `np-password-input-action` button inside the root with a `data-action`. Always give it an `aria-label`.

<ComponentPreview
  target="html"
  name="password-input-actions"
  styles={["/field/field.css"]}
  scripts={["/password-input/password-input.js"]}
/>

| Action | What it does |
| ------ | ------------ |
| `data-action="copy"` | Copies the value. The button gets `data-copied` and the label `Copied` for 1.5 seconds. |
| `data-action="clear"` | Empties the input and moves focus to it. |
| `data-action="generate"` | Fills in a random password. Set the length with `data-length` (default 16). |

`generate` and `clear` fire an `input` event, so the strength meter and the checklist update.

## Events and API

The script fires these events on the root. They bubble.

| Event | `detail` |
| ----- | -------- |
| `np-password-input:input` | `{ value, score }` |
| `np-password-input:visible` | `{ visible, reason }` with the reason `toggle-press`, `form-submit`, `reset`, `page-hide` or `imperative` |

```js
document.querySelector(".np-password-input").addEventListener("np-password-input:visible", (event) => {
  console.log(event.detail.visible, event.detail.reason)
})
```

Each root also gets a small API:

```js
const root = document.querySelector(".np-password-input")
root._npPasswordInput.setValue("correct horse")
root._npPasswordInput.setVisible(true)
root._npPasswordInput.getValue()
root._npPasswordInput.isVisible()
root._npPasswordInput.focus()
```

> **Note:** There is no `onVisibleChange` that can cancel a change in the HTML version. Use the [React version](/docs/components/react/password-input) for that, and for the controller.

| State | Selector |
| ----- | -------- |

| Copied | `[data-copied]` on an action |
