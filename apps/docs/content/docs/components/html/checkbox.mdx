## Usage

Link the component's CSS file to your HTML document.

```html
<head>
  <link rel="stylesheet" href="./styles/checkbox.css">
</head>
```

Then add the `data-np-checkbox` attribute or `np-checkbox` class to your `<input>` element.
```html
<input data-np-checkbox type="checkbox" id="remember-me" />
<input type="checkbox" id="disabled-checkbox" disabled class="np-checkbox" />
```
