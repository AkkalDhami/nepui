## Usage

```html
<link rel="stylesheet" href="./styles/toggle.css" />
<script src="./javascripts/toggle.js" defer></script>
```

```html
<button type="button" class="np-toggle" aria-pressed="false" aria-label="Toggle bold">
  Bold
</button>
```

Or use the data attribute instead of the class:

```html
<button type="button" data-np-toggle aria-pressed="false" aria-label="Toggle bold">
  Bold
</button>
```

The stylesheet only reads `aria-pressed`. <LINK href="#behavior">`toggle.js`</LINK> is the small script that flips it.

Icon-only toggles have no visible text, so always give them an `aria-label`.

---

## Behavior

`toggle.js` flips `aria-pressed` when a toggle is clicked. Load it once with `defer` and it handles every toggle on the page, including toggles added later.

It skips toggles inside a [Toggle Group](/docs/components/html/toggle-group), which are handled by `toggle-group.js`. Load both scripts if you use both, and never add an inline `onclick` to a toggle.

The script is optional. Skip it if you manage `aria-pressed` yourself, for example with htmx, Alpine or your own code. React users do not need it either, Base UI handles it.

### Change event

The toggle fires `np-toggle-change` after every change. It bubbles, so you can listen on the toggle or on `document`.

```js
document.addEventListener("np-toggle-change", (event) => {
  const toggle = event.target
  const { pressed } = event.detail
})
```

Disabled toggles (`disabled`, `aria-disabled="true"` or `data-disabled`) ignore clicks. `Enter` and `Space` press the focused toggle, as with any button.

## Reference

### Variants

| Name    | Data attribute          | Class alias         |
| ------- | ----------------------- | ------------------- |
| Default | -                       | `np-toggle`         |
| Outline | `data-variant="outline"` | `np-toggle-outline` |

### Sizes

| Name    | Data attribute     | Class alias     |
| ------- | ------------------ | --------------- |
| Small   | `data-size="sm"`   | `np-toggle-sm`  |
| Default | -                  | `np-toggle`     |
| Large   | `data-size="lg"`   | `np-toggle-lg`  |

### Features

| Name      | Data attribute   | Class alias            |
| --------- | ---------------- | ---------------------- |
| Fill icon | `data-fill-icon` | `np-toggle-fill-icon`  |

### States

| State    | Selector                                              |
| -------- | ----------------------------------------------------- |
| Pressed  | `[aria-pressed="true"]`, `[data-pressed]`             |
| Disabled | `:disabled`, `[aria-disabled="true"]`, `[data-disabled]` |
| Invalid  | `[aria-invalid="true"]`, `[data-invalid]`             |
