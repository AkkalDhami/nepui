## Usage

Link the tokens and the stylesheet:

```html
<link rel="stylesheet" href="./styles/tokens.css">
<link rel="stylesheet" href="./styles/item.css">
```

Add the classes:

```html
<div class="np-item np-item-outline">
  <div class="np-item-media np-item-media-icon">
    <svg>...</svg>
  </div>
  <div class="np-item-content">
    <div class="np-item-title">Title</div>
    <p class="np-item-description">Description</p>
  </div>
  <div class="np-item-actions">
    <button class="np-button np-button-outline np-button-sm" type="button">Action</button>
  </div>
</div>
```

Or use the data attributes instead of the classes:

```html
<div data-np-item data-variant="outline">
  <div data-np-item-media data-variant="icon">...</div>
  <div data-np-item-content>
    <div data-np-item-title>Title</div>
    <p data-np-item-description>Description</p>
  </div>
</div>
```

Item needs no JavaScript. Interactivity comes from the native element you choose: use an `a` for navigation or a `button` for an action.

## States

Add `aria-current` (or `data-selected`) to mark an item as selected. An `a`, a `button` or an element with `data-interactive` gets hover styles. `aria-disabled="true"`, `data-disabled` or a disabled button dims the item and blocks pointer events.
