## Usage

Link the stylesheet:

```html
<link rel="stylesheet" href="./styles/marker.css">
```

```html
<div class="np-marker">
  <span class="np-marker-icon" aria-hidden="true"><svg>...</svg></span>
  <span class="np-marker-content">Explored 4 files</span>
</div>
```

Or use the data attributes instead of classes:

```html
<div data-np-marker>
  <span data-np-marker-icon aria-hidden="true"><svg>...</svg></span>
  <span data-np-marker-content>Explored 4 files</span>
</div>
```

Add `aria-hidden="true"` to the icon slot yourself, since plain HTML cannot do it for you.

## Features

- Inline marker, bordered row and labeled separator variants.
- A decorative icon slot that is hidden from assistive tech.
- Use a `<a>` or `<button>` as the root for link and button markers.
- A shimmer effect for streaming status text, and a spinning icon for progress.
- A vertical layout that stacks the icon above the text.

## Accessibility

`Marker` is presentational by default. The right semantics depend on how you use it, so choose the role by intent.

### Status and Progress

For streaming or progress markers such as "Thinking..." or a running tool, set `role="status"` so assistive tech announces the update as it appears.

### Labeled Separators

A separator that carries text, such as a date or a section label, needs no role. The divider lines are decorative CSS, and the text is announced as ordinary content. Do not add `role="separator"` to a labeled divider: a separator takes its name from `aria-label`, so the visible label would not be announced.

### Bordered Markers

A bordered marker has the same semantics as the default one. The bottom border is decorative, so choose `role="status"`, a link or button, or no role, based on its purpose.

### Decorative Icons

The icon slot is hidden from assistive tech with `aria-hidden`, so the text next to it carries the meaning. For an icon-only marker, give the marker an `aria-label` or visible text so it is not announced as empty.

### Interactive Markers

When a marker links or triggers an action, render it as a real `<a>` or `<button>` so it is focusable and has the right role. The accessible name comes from the marker text.
