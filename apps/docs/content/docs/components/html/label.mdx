## Usage

Link the component's CSS file to your HTML document.

```html
<head>
  <link rel="stylesheet" href="./styles/label.css">
</head>
```

Then add the `data-np-label` attribute or `np-label` class to your `<label>` element.
```html
<label data-np-label for="email">Your email address</label>
<label for="terms" class="np-label">Terms and conditions</label>
```
