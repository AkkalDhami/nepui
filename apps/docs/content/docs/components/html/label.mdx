## Usage

Link the design tokens and the component's CSS file to your HTML document.

```html
<head>
  <link rel="stylesheet" href="./styles/tokens.css">
  <link rel="stylesheet" href="./styles/label.css">
</head>
```

Then add the `data-np-label` attribute or `np-label` class to your `<label>` element.
```html
<label data-np-label for="email">Your email address</label>
<label for="terms" class="np-label">Terms and conditions</label>
```

## Label in Field

For form fields, use the [Field](/docs/components/html/field) component which
includes built-in `FieldLabel`, `FieldDescription`, and `FieldError` components.

```tsx
<div class="np-field">
  <label class="np-field-label" for="name">Full name</label>
  <input id="name" class="np-input" />
</div>
```
