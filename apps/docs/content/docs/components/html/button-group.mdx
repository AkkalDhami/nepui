## Usage

Link the design tokens, [Button](/docs/components/html/button) stylesheet and the component's CSS file to your HTML document.

```html
<head>
  <link rel="stylesheet" href="./styles/tokens.css">
  <link rel="stylesheet" href="./styles/button.css">
  <link rel="stylesheet" href="./styles/button-group.css">
</head>
```

Then, add the `np-button-group` class to a container and place your buttons inside it.

```html
<div class="np-button-group" role="group">
  <button class="np-button np-button-outline">Archive</button>
  <button class="np-button np-button-outline">Report</button>
  <button class="np-button np-button-outline">Snooze</button>
</div>
```

You can also use the `data-np-button-group` attribute instead of the class.

```html
<div data-np-button-group role="group">
  <button data-np-button data-variant="outline">Archive</button>
  <button data-np-button data-variant="outline">Report</button>
</div>
```

The group connects its direct children: inner corners are squared and shared borders are collapsed.

## Composition

Use the following composition to build a `ButtonGroup`:

```text
ButtonGroup
├── Button or Input
├── ButtonGroupSeparator
└── ButtonGroupText
```

---

## Accessibility

Add `role="group"` to the container and give it an accessible name with `aria-label` or `aria-labelledby`.

```html
<div class="np-button-group" role="group" aria-label="Text alignment">
  ...
</div>
```

Use `data-orientation="vertical"` or the `np-button-group-vertical` class to stack the buttons.

| Orientation | Data attribute                | Class alias                |
| ----------- | ----------------------------- | -------------------------- |
| Horizontal(Default)  | `data-orientation="horizontal"` | `np-button-group`        |
| Vertical    | `data-orientation="vertical"` | `np-button-group-vertical` |

## Separator

Add a divider between buttons with `np-button-group-separator` or `data-np-button-group-separator`. It is useful for buttons that have no border, such as the `secondary` variant.

<ComponentPreview
  name="button-group-separator"
  styles={["/button/button.css"]}
  target="html"
/>

The separator is vertical by default, for horizontal groups. In a vertical group, use `np-button-group-separator-horizontal` or `data-orientation="horizontal"`.

| Orientation | Data attribute                  | Class alias                            |
| ----------- | ------------------------------- | -------------------------------------- |
| Vertical    | `data-orientation="vertical"`   | `np-button-group-separator`            |
| Horizontal  | `data-orientation="horizontal"` | `np-button-group-separator-horizontal` |

## Class and data attributes

| Part                 | Class                                  | Data attribute                   |
| -------------------- | -------------------------------------- | -------------------------------- |
| Group                | `np-button-group`                      | `data-np-button-group`           |
| Vertical group       | `np-button-group-vertical`             | `data-orientation="vertical"`    |
| Text                 | `np-button-group-text`                 | `data-np-button-group-text`      |
| Separator            | `np-button-group-separator`            | `data-np-button-group-separator` |
| Horizontal separator | `np-button-group-separator-horizontal` | `data-orientation="horizontal"`  |
