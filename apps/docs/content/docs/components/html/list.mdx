`list.js` is optional. Plain lists, markers, nesting and variants are pure CSS. Load the script only for keyboard navigation, collapsible branches and selection.

## Usage

```html
<link rel="stylesheet" href="./styles/list.css" />

<script src="./javascripts/list.js" defer></script>
```

```html
<ul class="np-list" aria-label="Launch checklist">
  <li>Write the release notes</li>
  <li>Tag the version in Git</li>
  <li>Publish the package</li>
</ul>
```

Or with the data attribute:

```html
<ul data-np-list aria-label="Launch checklist">
  <li>Write the release notes</li>
  <li>Tag the version in Git</li>
  <li>Publish the package</li>
</ul>
```

Every nested `ul` or `ol` needs the `np-list` class (or `data-np-list`) too. That gives it its own marker, indentation and options.

## Composition

## Collapsible

Load `list.js`, then add `data-collapsible` to the root list. The script wraps each item label, adds a toggle button to every item that has a nested list, and wires `aria-expanded` and `aria-controls`. Add `data-collapsed` to an item to start it closed.

<ComponentPreview
  target="html"
  name="list-collapsible"
  styles={["/button/button.css"]}
  scripts={["/list/list.js"]}
/>

The script also exposes a small API:

```js
const list = NepuiList.get(document.querySelector("#files"))

list.expandAll()
list.collapseAll()
list.toggle(item)
list.focus(item)
```

Events bubble from the root list:

```js
list.root.addEventListener("np-list-toggle", (event) => {
  console.log(event.detail.item, event.detail.expanded)
})
```

`NepuiList.init()` runs on page load. Call `NepuiList.init(container)` after you insert lists into the page later.

## Keyboard navigation

Add `data-navigation` to the root list (it needs `list.js`). The list becomes a single tab stop and arrow keys move focus between items. Add `data-loop` to wrap around at either end.

| Key | Action |
| --- | --- |
| `ArrowDown` / `ArrowUp` | Move to the next or previous visible item |
| `ArrowRight` | Expand a collapsed branch, or move to its first child |
| `ArrowLeft` | Collapse an expanded branch, or move to the parent |
| `Home` / `End` | Move to the first or last visible item |
| `Enter` / `Space` | Toggle a branch, or select the item when selection is on |
| `*` | Expand every branch at the current level |
| Letters | Jump to the next item that starts with the typed text |
| `Shift` + `ArrowDown` / `ArrowUp` | Extend the selection (`data-selection="multiple"`) |
| `Ctrl` / `Cmd` + `A` | Select every visible item (`data-selection="multiple"`) |

---

## Selection

Add `data-selection="single"` or `"multiple"` to the root list. The script sets `role="listbox"` on the list and `role="option"` and `aria-selected` on each item. Give items a `data-value`, and add `data-selected` to preselect one. Selection is for flat lists.

## Accessibility

- Plain lists keep native `ul`, `ol` and `li` semantics. Give a list an `aria-label` when it is not introduced by a heading.
- With `data-navigation`, items use a roving `tabindex`, so the list is one tab stop.
- Each toggle is a real `button` with `aria-expanded`, `aria-controls` and a name taken from the item text. It is removed from the tab order when navigation is on, and arrow keys do the same job.
- Focus rings use `:focus-visible`, and forced-colors mode gets an outline.
- Toggle motion is removed under `prefers-reduced-motion`.
- Collapsed branches use `display: none`, so they leave the accessibility tree.
- CSS needs `:has()`, `:is()` and `color-mix()`. All three are supported in current browsers.

## Reference

### Parts

| Part | Class | Data attribute |
| --- | --- | --- |
| List (`ul` or `ol`) | `np-list` | `data-np-list` |
| Item (optional, any direct `li` is styled already) | `np-list-item` | `data-np-list-item` |
| Label (wraps the text of an item that has a nested list) | `np-list-label` | `data-np-list-label` |
| Toggle (button inside the label) | `np-list-toggle` | `data-np-list-toggle` |

`list.js` adds the label, the toggle and an inner `np-list-text` span for you, so you rarely write them by hand. Every nested `ul` or `ol` needs `np-list` (or `data-np-list`) too.

### Behaviour attributes

These are read by `list.js` and do nothing without it. Set them on the root list unless noted.

| Attribute | Values | Description |
| --- | --- | --- |
| `data-navigation` | boolean | Roving tabindex and arrow-key navigation. |
| `data-loop` | boolean | Wrap from the last item to the first and back. |
| `data-collapsible` | boolean | Add a toggle to every item that has a nested list. |
| `data-selection` | `single` \| `multiple` | Turn the list into a listbox. Flat lists only. |
| `data-collapsed` | boolean (on `li`) | Start the item's nested list closed. The script keeps it in sync. |
| `data-selected` | boolean (on `li`) | Preselect the item. The script keeps it in sync. |
| `data-disabled` or `aria-disabled="true"` | (on `li`) | Skip the item in navigation and selection. |
| `data-value` | string (on `li`) | Value reported on selection. Defaults to the item text. |

### Attributes set by the script

| Attribute | On | When |
| --- | --- | --- |
| `role="listbox"`, `aria-multiselectable` | root list | `data-selection` is set. |
| `role="option"`, `aria-selected` | `li` | `data-selection` is set. |
| `tabindex="0"` or `"-1"` | `li` | `data-navigation` is set (roving tabindex). |
| `aria-expanded`, `aria-controls`, `aria-labelledby` | toggle | `data-collapsible` is set. |
| `tabindex="-1"` | toggle | `data-navigation` is also set. |
| `data-collapsible` | nested lists | Copied from the root so leaf items line up with items that have a toggle. |

### Script

`window.NepuiList`

| Method | Description |
| --- | --- |
| `init(scope?)` | Enhance every top-level list with `data-navigation`, `data-collapsible` or `data-selection` inside `scope` (default `document`). Runs on page load. |
| `create(list)` | Enhance one list and return its instance. |
| `get(list)` | Return the instance of an enhanced list, or `null`. |

Instance

| Member | Description |
| --- | --- |
| `root` | The list element. |
| `value` | Array of selected item values. |
| `expand(item)` / `collapse(item)` / `toggle(item)` | Open, close or flip one item's nested list. |
| `expandAll()` / `collapseAll()` | Open or close every branch. |
| `focus(item)` | Make the item the tab stop and focus it. |
| `select(item)` | Select an item (toggles it in `multiple` mode). |
| `selectAll()` / `clear()` | Select every visible item, or clear the selection. |
| `destroy()` | Remove the listeners. Attributes the script added stay in place. |

### Events

Both events bubble from the root list.

| Event | When | `event.detail` |
| --- | --- | --- |
| `np-list:toggle` | A branch opens or closes. | `{ item, expanded }` |
| `np-list:change` | The selection changes. | `{ value }` (array of values) |
