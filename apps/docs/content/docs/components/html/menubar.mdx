## Usage

Opening menus, hover switching, arrow-key navigation and submenus cannot be done with CSS alone, so the HTML version ships a small script (no dependencies). Without it the menus stay closed.

```html
<link rel="stylesheet" href="./styles/menubar.css">

<script src="./javascripts/menubar.js" defer></script>
```

Structure: a bar, one `np-menubar-menu` per menu, and inside it a trigger button and the content (closed with the `hidden` attribute). The script fills in missing ids, `aria-controls` and `aria-labelledby`.

```html
<div class="np-menubar" role="menubar" aria-label="Application menu">
  <div class="np-menubar-menu">
    <button class="np-menubar-trigger" type="button" aria-haspopup="menu" aria-expanded="false">File</button>
    <div class="np-menubar-content" role="menu" hidden>
      <div role="group">
        <div class="np-menubar-item" role="menuitem" tabindex="-1">
          New Tab <span class="np-menubar-shortcut">⌘T</span>
        </div>
        <div class="np-menubar-item" role="menuitem" tabindex="-1">New Window</div>
      </div>
      <div class="np-menubar-separator" role="separator"></div>
      <div role="group">
        <div class="np-menubar-item" role="menuitem" tabindex="-1">Share</div>
        <div class="np-menubar-item" role="menuitem" tabindex="-1">Print</div>
      </div>
    </div>
  </div>
</div>
```

Or use the data attributes instead of classes:

```html
<div data-np-menubar role="menubar">
  <div data-np-menubar-menu>
    <button data-np-menubar-trigger type="button">File</button>
    <div data-np-menubar-content hidden>
      <div data-np-menubar-item>New Tab <span data-np-menubar-shortcut>⌘T</span></div>
      <div data-np-menubar-item data-variant="destructive">Delete</div>
    </div>
  </div>
</div>
```

Menus open below their trigger without collision handling. Leave room below the bar, or open the bar near the top of the page.

Listen for activated items with the `np-menubar-select` event. It bubbles and `event.detail.item` is the item.

```js
document.querySelector(".np-menubar").addEventListener("np-menubar-select", (event) => {
  console.log(event.detail.item.textContent.trim())
})
```

For menus added later, call `NepuiMenubar.init(container)`.

## Composition

Use the following composition to build a `Menubar`:

```text
np-menubar
├── np-menubar-menu
│   ├── np-menubar-trigger
│   └── np-menubar-content
│       ├── np-menubar-group
│       │   ├── np-menubar-label
│       │   ├── np-menubar-item
│       │   └── np-menubar-item
│       ├── np-menubar-separator
│       ├── np-menubar-group
│       │   ├── np-menubar-label
│       │   ├── np-menubar-checkbox-item
│       │   └── np-menubar-checkbox-item
│       ├── np-menubar-separator
│       ├── np-menubar-group
│       │   ├── np-menubar-label
│       │   └── np-menubar-radio-group
│       │       ├── np-menubar-radio-item
│       │       └── np-menubar-radio-item
│       └── np-menubar-sub
│           ├── np-menubar-sub-trigger
│           └── np-menubar-sub-content
│               └── np-menubar-group
│                   ├── np-menubar-label
│                   ├── np-menubar-item
│                   └── np-menubar-item
└── np-menubar-menu
    ├── np-menubar-trigger
    └── np-menubar-content
        └── np-menubar-group
            ├── np-menubar-label
            ├── np-menubar-item
            └── np-menubar-item
```

## Disabled

Add `aria-disabled="true"` (or `data-disabled`) to an item. Add `disabled` to a trigger. Disabled items are dimmed, ignore the pointer and are skipped by keyboard navigation.

```html
<div class="np-menubar-item" role="menuitem" tabindex="-1" aria-disabled="true">Print</div>
```

## Keyboard

| Key                                | Action                                                          |
| ---------------------------------- | --------------------------------------------------------------- |
| `ArrowLeft` / `ArrowRight`         | Move between triggers. In an open menu, open the next or previous menu. Swapped in RTL. |
| `ArrowDown` / `ArrowUp`            | On a trigger, open the menu on its first or last item. In a menu, move between items. |
| `Home` / `End`                     | First or last trigger, or first or last item.                   |
| `Enter` / `Space`                  | Open a menu, open a submenu, or activate an item.               |
| `ArrowRight` on a sub trigger      | Open the submenu. `ArrowLeft` closes it (swapped in RTL).       |
| Letter                             | Jump to the next item that starts with it.                      |
| `Escape`                           | Close everything and focus the trigger.                         |
| `Tab`                              | Close the menu.                                                 |

| Checkbox item     | `data-np-menubar-checkbox-item`   | `np-menubar-checkbox-item`   |
| Radio item        | `data-np-menubar-radio-item`      | `np-menubar-radio-item`      |
| Item indicator    | `data-np-menubar-item-indicator`  | `np-menubar-item-indicator`  |

| Separator         | `data-np-menubar-separator`       | `np-menubar-separator`       |

### Variants

| Name        | Data attribute               | Class alias            | On                               |
| ----------- | ---------------------------- | ---------------------- | -------------------------------- |
| Destructive | `data-variant="destructive"` | `np-menubar-destructive` | Item                           |
| Inset       | `data-inset`                 | `np-menubar-inset`     | Item, checkbox, radio, sub trigger, label |

### States

| State       | Selector                                  |
| ----------- | ----------------------------------------- |
| Open        | `aria-expanded="true"` or `data-popup-open` |
| Highlighted | `:focus` or `data-highlighted`            |
| Checked     | `aria-checked="true"` or `data-checked`   |
| Disabled    | `aria-disabled="true"` or `data-disabled` |
