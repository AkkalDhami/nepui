## Usage

Link the stylesheets, after `tokens.css` and `button.css`, and the optional script:

```html
<link rel="stylesheet" href="./styles/button.css">
<link rel="stylesheet" href="./styles/carousel.css">

<script src="./javascripts/carousel.js" defer></script>
```

```html
<div class="np-carousel" role="region" aria-roledescription="carousel" aria-label="Photos">
  <div class="np-carousel-viewport">
    <div class="np-carousel-content">
      <div class="np-carousel-item" role="group" aria-roledescription="slide" aria-label="1 of 3">...</div>
      <div class="np-carousel-item" role="group" aria-roledescription="slide" aria-label="2 of 3">...</div>
      <div class="np-carousel-item" role="group" aria-roledescription="slide" aria-label="3 of 3">...</div>
    </div>
  </div>
  <button type="button" class="np-button np-button-outline np-button-icon-sm np-carousel-previous"
    aria-label="Previous slide"><svg ...></svg></button>
  <button type="button" class="np-button np-button-outline np-button-icon-sm np-carousel-next"
    aria-label="Next slide"><svg ...></svg></button>
</div>
```

Or use the data attributes instead of classes: `data-np-carousel`, `data-np-carousel-viewport`, `data-np-carousel-content`, `data-np-carousel-item`, `data-np-carousel-previous`, `data-np-carousel-next`, `data-np-carousel-dots`.

The HTML version scrolls natively with CSS scroll-snap, so touch, trackpad and wheel work with no JavaScript. The viewport is the scroller. `carousel.js` only wires the buttons and the arrow keys.

## Dots

Add an empty `<div class="np-carousel-dots"></div>` (or `data-np-carousel-dots`) after the buttons. `carousel.js` fills it with one dot per position, jumps to a slide on click, and marks the current dot with `aria-current="true"`. Without the helper the container stays empty.

## Slide counter

The helper fires `np-carousel-change` on the root, with `detail.index` and `detail.count`.

```js
root.addEventListener("np-carousel-change", (event) => {
  console.log(event.detail.index + 1, event.detail.count)
})
```

## Accessibility

- The root is a `region` with `aria-roledescription="carousel"`; give it an `aria-label`. Each slide is a `group` with `aria-roledescription="slide"`.
- The previous and next buttons have labels and are disabled at the ends.
- Arrow keys step through the slides when focus is inside the carousel.

## Reference
 
### Component
 
Classes and data attributes do exactly the same thing.
 
| Class | Attribute | Element |
| --- | --- | --- |
| `np-carousel` | `data-np-carousel` | Root |
| `np-carousel-viewport` | `data-np-carousel-viewport` | Clips the slides and scrolls |
| `np-carousel-content` | `data-np-carousel-content` | The row of slides |
| `np-carousel-item` | `data-np-carousel-item` | One slide |
| `np-carousel-previous` | `data-np-carousel-previous` | Previous button |
| `np-carousel-next` | `data-np-carousel-next` | Next button |
| `np-carousel-dots` | `data-np-carousel-dots` | Empty container the script fills with dots |
| `np-carousel-dot` | `data-np-carousel-dot` | One dot, created by the script |
| `np-carousel-vertical` | `data-orientation="vertical"` | Vertical carousel, on the root |
 
### Script
 
Link `carousel.js` after the markup. It is optional, has no dependencies and starts itself.
 
```html
<script src="./javascripts/carousel.js" defer></script>
```
 
It handles:
 
- The previous and next buttons: one slide at a time.
- Disabling the buttons at the start and at the end.
- The dots: it fills `np-carousel-dots`, jumps to a slide on click and sets `aria-current="true"` on the current dot.
- Mouse drag: drag the slides, and they snap to the nearest one on release. A short drag (under 15% of a slide) stays on the same slide, and a click after a drag is ignored. Touch already scrolls natively.
- Arrow keys on the carousel (Up and Down when vertical).

| API | Description |
| --- | --- |
| `NepuiCarousel.init(root)` | Wires one carousel. Use it for a carousel added after the page loaded. |
| `NepuiCarousel.initAll()` | Wires every carousel on the page. |
| `np-carousel-change` | Event on the root. `event.detail` is `{ index, count }`. |
 
```js
document.addEventListener("np-carousel-change", (event) => {
  console.log(event.detail.index + 1, "of", event.detail.count)
})
```
