## Usage

Link the tokens, the Button styles and the stylesheet, and load the script once on the page:

```html
<link rel="stylesheet" href="./styles/tokens.css" />
<link rel="stylesheet" href="./styles/button.css" />
<link rel="stylesheet" href="./styles/alert-dialog.css" />
<script src="./javascripts/alert-dialog.js" defer></script>
```

Use a native [`<dialog>`](https://developer.mozilla.org/docs/Web/HTML/Element/dialog) with `role="alertdialog"`. Open it with a button that uses `commandfor` and `command="show-modal"`. Use a regular button for the action so it does not close the dialog; give the cancel button `commandfor` and `command="close"` to dismiss it:

```html
<button class="np-button np-button-outline" type="button"
  commandfor="confirm" command="show-modal">Show Dialog</button>

<dialog id="confirm" class="np-alert-dialog" role="alertdialog"
  aria-labelledby="confirm-title" aria-describedby="confirm-description">
  <div class="np-alert-dialog-header">
    <h2 id="confirm-title" class="np-alert-dialog-title">Are you absolutely sure?</h2>
    <p id="confirm-description" class="np-alert-dialog-description">
      This action cannot be undone.
    </p>
  </div>
  <div class="np-alert-dialog-footer">
    <button class="np-button np-button-outline" type="button"
      commandfor="confirm" command="close" value="cancel" autofocus>Cancel</button>
    <button class="np-button" type="button">Continue</button>
  </div>
</dialog>
```

Or use the data attributes instead of the classes: `data-np-alert-dialog`, `data-np-alert-dialog-header`, `data-np-alert-dialog-footer` and so on.

## Composition

Use the following composition to build an `AlertDialog`:

```text
AlertDialog
├── AlertDialogTrigger
└── AlertDialogContent
    ├── AlertDialogHeader
    │   ├── AlertDialogMedia
    │   ├── AlertDialogTitle
    │   └── AlertDialogDescription
    └── AlertDialogFooter
        ├── AlertDialogCancel
        └── AlertDialogAction
```

## How it works

The browser's native `dialog` element does the hard parts: it shows the panel in the top layer, makes the rest of the page inert, traps focus, closes on Escape and returns focus to the button. A click on the dimmed backdrop does not close it, which is what makes it an alert dialog.

The `commandfor` and `command` attributes open and close it without any JavaScript in browsers that support invoker commands. The script only adds that behavior where it is missing.

Put `autofocus` on the safest button, normally Cancel, so keyboard users start there. When Cancel closes the dialog, `dialog.returnValue` is set to the button's `value`.
