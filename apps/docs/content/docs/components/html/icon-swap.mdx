## Use cases

- Copy buttons that switch to a check on success.
- Toggle buttons such as play and pause.
- Icons that follow the selected tab or option.

## Usage

```html
<link rel="stylesheet" href="./styles/icon-swap.css">
```

Put every icon in the stack. Mark the shown one with `data-active`. To swap, move `data-active` to another item and the CSS animates both: the old icon scales down, blurs and fades while the new one comes in.

```html
<button class="np-button np-button-outline np-button-icon-sm" type="button" aria-label="Copy" id="copy">
  <span class="np-icon-swap">
    <span class="np-icon-swap-item" data-active><!-- copy icon svg --></span>
    <span class="np-icon-swap-item"><!-- check icon svg --></span>
  </span>
</button>
```

```js
const items = document.querySelectorAll("#copy .np-icon-swap-item")
items[0].toggleAttribute("data-active")
items[1].toggleAttribute("data-active")
```

Or use the data attributes instead of classes:

```html
<span data-np-icon-swap>
  <span data-np-icon-swap-item data-active>…</span>
  <span data-np-icon-swap-item>…</span>
</span>
```

Use icons with `aria-hidden="true"` and give the button an accessible name. If the meaning changes (for example Copy to Copied), update `aria-label` too, or use `aria-pressed` for toggles.

Because every icon stays in the DOM, this works with any way of changing an attribute: plain JavaScript, htmx, Alpine, or a framework.

## Reference

### Parts

| Name  | Data attribute              | Class alias           |
| ----- | --------------------------- | --------------------- |
| Stack | `data-np-icon-swap`         | `np-icon-swap`        |
| Item  | `data-np-icon-swap-item`    | `np-icon-swap-item`   |

### States

| Name                | Data attribute | Class alias            |
| ------------------- | -------------- | ---------------------- |
| Active (shown) item | `data-active`  | `np-icon-swap-active`  |

With `prefers-reduced-motion: reduce`, scale and blur are turned off and only the fade remains.
