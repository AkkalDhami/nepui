## Usage

Link the design tokens and component's CSS file to your HTML document.

```html
<head>
  <link rel="stylesheet" href="./styles/tokens.css">
  <link rel="stylesheet" href="./styles/progress.css">
</head>
```

Then, add the `np-progress` class to a native `<progress>` element. Set `value`, and set `max="100"` for a 0 to 100 scale.

```html
<progress class="np-progress" value="33" max="100" aria-label="Progress"></progress>
```

You can also use the `data-np-progress` attribute instead of the class.

```html
<progress data-np-progress value="33" max="100" aria-label="Progress"></progress>
```

The native `max` defaults to `1`, so `value="33"` without `max="100"` shows a full bar.

## Parts

| Part                   | Class               | Data attribute           |
| ---------------------- | ------------------- | ------------------------ |
| Bar (`<progress>`)     | `np-progress`       | `data-np-progress`       |
| Root (label + bar)     | `np-progress-root`  | `data-np-progress-root`  |
| Label                  | `np-progress-label` | `data-np-progress-label` |
| Value text             | `np-progress-value` | `data-np-progress-value` |
