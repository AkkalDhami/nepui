## Installation

```bash
npx nepui@latest add spinner
```

---

## Usage

```html title="spinner.html" showLineNumbers {2} 
<html>
  <link rel="stylesheet" href="./styles/spinner.css">
</html>
```

After installing the component, add the `data-np-spinner` attribute or the class alias `np-spinner` to an element:

```html title="spinner.html" showLineNumbers
<span data-np-spinner></span>
<span class="np-spinner"></span>
```

## Size

Use the `data-size` attribute or the class alias to control the spinner size.

<HtmlPreviewTabs
  className="mt-4"
  cssPath="registry/html/spinner/spinner.css"
  html={`
<span class="np-spinner" data-size="xs"></span>
<span class="np-spinner" data-size="sm"></span>
<span class="np-spinner np-spinner-md"></span>
<span class="np-spinner" data-size="lg"></span>
<span class="np-spinner np-spinner-xl"></span>
  `}
      >
```html title="spinner.html" showLineNumbers
<span class="np-spinner" data-size="xs"></span>

<span class="np-spinner" data-size="sm"></span>

<span class="np-spinner np-spinner-md"></span>

<span class="np-spinner" data-size="lg"></span>

<span class="np-spinner np-spinner-xl"></span>
```
</HtmlPreviewTabs>

Use the `--np-spinner-size` custom property to control the spinner size.

<HtmlPreviewTabs
  className="mt-4"
  cssPath="registry/html/spinner/spinner.css"
  html={`
<span class="np-spinner" style="--np-spinner-size: 5rem"></span>
  `}
      >
```html title="spinner.html" showLineNumbers
<span class="np-spinner" style="--np-spinner-size: 5rem"></span>
```
</HtmlPreviewTabs>

| Size | Data attribute | Class alias |
| ---- | -------------- | ----------- |
| Extra small   | `data-size="xs"` | `np-spinner-xs` |
| Small         | `data-size="sm"` | `np-spinner-sm` |
| Medium (default)       | `data-size="md"` | `np-spinner-md` |
| Large         | `data-size="lg"` | `np-spinner-lg` |
| Extra large   | `data-size="xl"` | `np-spinner-xl` |

## Color

Use the `--np-spinner-color` and `--np-spinner-muted-color` CSS custom property to customize the spinner's color.

<HtmlPreviewTabs
className="mt-4"
cssPath="registry/html/spinner/spinner.css"
html={` <span class="np-spinner" style="--np-spinner-color: tomato"></span>

<span class="np-spinner" style="--np-spinner-color: #2563eb"></span>

<span class="np-spinner" style="--np-spinner-color: rgb(34 197 94)"></span>

<span class="np-spinner" style="--np-spinner-color: #d80606ff; --np-spinner-muted-color: #0211b7ff"></span>
`}
>

```html title="spinner.html" showLineNumbers
<span class="np-spinner" style="--np-spinner-color: tomato"></span>

<span class="np-spinner" style="--np-spinner-color: #2563eb"></span>

<span class="np-spinner" style="--np-spinner-color: rgb(34 197 94)"></span>

<span
  class="np-spinner"
  style="--np-spinner-color: #d80606ff; --np-spinner-muted-color: #0211b7ff"
></span>
```

</HtmlPreviewTabs>

| Color           | CSS custom property                                                  |
| --------------- | -------------------------------------------------------------------- |
| Primary         | `--np-spinner-color: tomato`                                         |
| Primary         | `--np-spinner-color: #2563eb`                                        |
| Primary         | `--np-spinner-color: rgb(34 197 94)`                                 |
| Primary + muted | `--np-spinner-color: #d80606ff; --np-spinner-muted-color: #0211b7ff` |
