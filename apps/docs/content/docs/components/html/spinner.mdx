## Usage

Link the component's CSS file to your HTML document.

```html title="spinner.html" showLineNumbers {2}
<html>
  <link rel="stylesheet" href="./styles/spinner.css">
</html>
```

Then, add the `data-np-spinner` attribute or the class alias `np-spinner` to an element:

```html title="spinner.html" showLineNumbers
<span data-np-spinner></span>
<span class="np-spinner"></span>
<span class="np-spinner" data-size="lg"></span>
<span class="np-spinner" data-speed="fast"></span>
<span class="np-spinner" data-thickness="medium"></span>
<span class="np-spinner-counter-clockwise" data-np-spinner></span>
```

## Size

Use the `data-size` attribute or the class alias to control the spinner size.

<ComponentPreview
  name="spinner-size"
  target="html"
/>

Use the `--np-spinner-size` custom property to control the spinner size.

```html title="spinner.html" showLineNumbers
<span class="np-spinner" style="--np-spinner-size: 5rem"></span>
```

| Size | Data attribute | Class alias |
| ---- | -------------- | ----------- |
| Extra small   | `data-size="xs"` | `np-spinner-xs` |
| Small         | `data-size="sm"` | `np-spinner-sm` |
| Medium (default)       | `data-size="md"` | `np-spinner-md` |
| Large         | `data-size="lg"` | `np-spinner-lg` |
| Extra large   | `data-size="xl"` | `np-spinner-xl` |
