## Usage

Link the design tokens and the component's CSS file to your HTML document.

```html
<head>
  <link rel="stylesheet" href="./styles/tokens.css">
  <link rel="stylesheet" href="./styles/textarea.css">
</head>
```

Then, add the `np-textarea` class to your `<textarea>` element.

```html
<textarea class="np-textarea" placeholder="Type your message here."></textarea>
```

You can also use the `data-np-textarea` attribute instead of the class.

```html
<textarea data-np-textarea placeholder="Type your message here."></textarea>
```
