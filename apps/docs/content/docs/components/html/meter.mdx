## Usage

Link the design tokens and the component's CSS file to your HTML document.

```html
<head>
  <link rel="stylesheet" href="./styles/tokens.css">
<link rel="stylesheet" href="./styles/meter.css">
```

Use the native `<meter>` element as the track. The browser draws the bar from `value`, `min` and `max`, so there is nothing to calculate.

```html
<div class="np-meter">
  <label class="np-meter-label" for="storage">Storage usage</label>
  <span class="np-meter-value">75%</span>
  <meter class="np-meter-track" id="storage" value="75" min="0" max="100">75%</meter>
</div>
```

Or use the data attributes instead of classes:

```html
<div data-np-meter>
  <meter data-np-meter-track aria-label="Storage usage" value="75" min="0" max="100">75%</meter>
</div>
```

The text inside `<meter>` is only a fallback for very old browsers. The value text next to the label is plain text: write it yourself and keep it in sync with `value`.

The browser's own low, high and optimum colors are replaced by the meter color, so `low`, `high` and `optimum` do not change the look. Use the [variants](#variants) instead.

## Sizes

Add the alias next to `np-meter`, or set the data attribute.

  name="meter-sizes"
  target="html"

| Name | Data attribute | Class alias |
| ---- | -------------- | ----------- |
| Small | `data-size="sm"` | `np-meter-sm` |
| Default | - | `np-meter` |
| Large | `data-size="lg"` | `np-meter-lg` |

## Reference

| Name | Data attribute | Class alias |
| ---- | -------------- | ----------- |
| Meter | `data-np-meter` | `np-meter` |
| Label | `data-np-meter-label` | `np-meter-label` |
| Value | `data-np-meter-value` | `np-meter-value` |
| Track (`<meter>`) | `data-np-meter-track` | `np-meter-track` |

The indicator part is only used by the [React version](/docs/components/react/meter), which draws the bar with a `div`.
