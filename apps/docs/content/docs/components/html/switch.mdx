## Usage

Link the design tokens and the component's CSS file to your HTML document.

```html
<head>
  <link rel="stylesheet" href="./styles/tokens.css">
  <link rel="stylesheet" href="./styles/switch.css">
</head>
```

Use a native checkbox with `role="switch"`:

```html
<input class="np-switch" type="checkbox" role="switch" id="airplane-mode">
<label for="airplane-mode">Airplane mode</label>
```

Or use the data attribute instead of the class:

```html
<input data-np-switch type="checkbox" role="switch" id="airplane-mode">
```

## Invalid

Add `data-invalid` to the `np-field` and `aria-invalid="true"` (or `data-invalid`) to the input to show an error state. 

```html showLineNumbers /data-invalid/ /aria-invalid="true"/
<div class="np-field" data-orientation="horizontal" data-invalid>
  <div class="np-field-content">
    <label class="np-field-label" for="terms">Accept terms and conditions</label>
  </div>
  <input
    class="np-switch"
    type="checkbox"
    role="switch"
    id="terms"
    aria-invalid="true"
  />
</div>
```

This also needs `field.css`.

```html
<link rel="stylesheet" href="./styles/field.css">
<link rel="stylesheet" href="./styles/switch.css">
```

## Disabled

Add `disabled` to the input. Add `data-disabled` to the `np-field` to dim the label too.

```html showLineNumbers /data-disabled/ /disabled/
<div
  class="np-field np-field-horizontal"
  data-disabled
  style="width: fit-content"
>
  <input
    class="np-switch"
    type="checkbox"
    role="switch"
    id="sw-dis-off"
    disabled
  />
  <label class="np-field-label" for="sw-dis-off">Disabled</label>
</div>
```

Link the following stylesheets:

```html
<link rel="stylesheet" href="./styles/field.css">
<link rel="stylesheet" href="./styles/switch.css">
```
