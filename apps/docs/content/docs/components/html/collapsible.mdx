## Usage

Link the tokens and the stylesheet:

```html
<link rel="stylesheet" href="./styles/tokens.css">
<link rel="stylesheet" href="./styles/collapsible.css">
```

Use a `details` element. The `summary` must come first, and it is the trigger:

```html
<details class="np-collapsible">
  <summary class="np-collapsible-trigger">Can I use this in my project?</summary>
  <div class="np-collapsible-content">
    Yes. Free to use for personal and commercial projects.
  </div>
</details>
```

Or use the data attributes instead of the classes:

```html
<details data-np-collapsible>
  <summary data-np-collapsible-trigger>Toggle</summary>
  <div data-np-collapsible-content>Content</div>
</details>
```

Add `open` to start expanded. The browser handles the keyboard, `aria-expanded` and find-in-page for you, so no JavaScript is needed.

---

## Icon

Give an icon the `np-collapsible-icon` class (or `data-np-collapsible-icon`) inside the trigger to rotate it when the panel is open. The default is 180 degrees. Set `--np-collapsible-icon-rotate` on the icon to change it.
