title: CLI
description: Initialize a project and install nepui components from the command line.

Use the nepui CLI to initialize a project and add component source files directly into your app.

```bash
npx nepui@latest init --target react
npx nepui@latest init --target html

npx nepui@latest add button --target react
npx nepui@latest add button card spinner --target html
npx nepui@latest add --all --target react
```

No separate install step is required. Run the CLI on demand with `npx`, or pin a version in CI with `npx nepui@latest`.

## Initialize a project

```bash
npx nepui@latest init [directory] --target <html|react>
```

`init` creates the base nepui token stylesheet for your project and sets up the correct folder structure for the selected target.

Examples:

```bash
npx nepui@latest init --target react
npx nepui@latest init --target html
```

```bash
npx nepui@latest init --target react .
npx nepui@latest init --target react my-app
npx nepui@latest init --target html my-app
```

```bash
npx nepui@latest init
```

If you do not pass a directory, the CLI prompts you for the target and folder.

For React projects, it writes the base token file to `components/nepui/tokens.css`.
For HTML projects, it writes it to `styles/tokens.css`.

React initialization also installs the required dependencies for the project when needed.

## Install components

```bash
npx nepui@latest add <component> [<component>...] --target <html|react>
```

You can add:

- one component
- multiple components
- every available component with `--all`

Examples:

```bash
npx nepui@latest add button --target react
npx nepui@latest add button card spinner --target react
npx nepui@latest add button card spinner --target html
npx nepui@latest add --all --target html
npx nepui@latest add --all --target react
```

The default target is `html`.

If a destination file already exists, the CLI asks whether to overwrite it, skip it, or cancel. Nothing is silently replaced. An unknown component name or an invalid `--target` value fails immediately, and no files are written.

Use either component names or `--all`; do not combine them in the same command.

## List available components

```bash
npx nepui list [--target <html|react>] [--json]
```

Aliases:

```bash
npx nepui ls
npx nepui ls --target react
npx nepui ls --json
npx nepui ls --json --target react
```

By default, the CLI lists components for the `html` target. Plain output is an alphabetical list. With `--json`, it prints only the JSON object to stdout, which is safe to pipe into tools like `jq`.
