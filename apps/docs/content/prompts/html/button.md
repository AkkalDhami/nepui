# Add the nepui Button (plain HTML)

Add the nepui **Button** component to my project using the nepui CLI. Do not write the component yourself.

## Steps

1. Look at my project. Find the package manager (npm, pnpm, yarn or bun) and where my components live.
2. Run the install command with my package manager's runner (`npx`, `pnpm dlx`, `yarn dlx` or `bunx`):

   ```bash
   npx nepui@latest add button
   ```

3. If the CLI asks questions, choose **plain HTML** and accept the defaults for paths unless they clash with my project. If it fails, show me the error and stop. Do not work around it by hand.
4. Read the files the CLI added. They are the source of truth for the props, attributes and options. Do not guess them.
5. Link the added stylesheets in the `<head>` of the page I name, in the order the CLI documents. Do not add a script unless the CLI added one.
6. Show me one short example of using the Button, based on what you read in step 4. Use plain HTML markup.

## Rules

- Do not edit the files the CLI added unless I ask you to.
- Do not change any other component or file I did not name.
- If the CLI adds a `tokens.css` or other shared files, keep them as they are.

## Reply

End with a short note: the command you ran, the files it added and where, and anything you could not check. Do not recap your steps.
