Class form

class="np-aspect-ratio" is 16 / 9 by default. A direct img fills the box.

Data-attribute form

data-np-aspect-ratio, no class needed.

Presets

np-aspect-ratio-square and np-aspect-ratio-portrait, or data-ratio.

Custom ratio

Set --np-aspect-ratio-value, for example 3 / 2 or 2.39.

Fit

--np-aspect-ratio-fit: contain shows the whole image instead of cropping it.

Any content

Other children size themselves. Give them height: 100% to fill.
