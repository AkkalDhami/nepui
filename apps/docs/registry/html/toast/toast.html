Basic

A button with data-np-toast-trigger and data-toast-* options. Hover the stack to expand it, swipe a toast away, or press Escape on a focused one.

Types

data-toast-type adds a status icon.

Action

data-toast-action adds a button that closes the toast.

Promise

Loading, then success or error, in one toast.

JavaScript

The same API from your own code through window.npToast.
