Class form

class="np-checkbox-group" on a role="group" element.

Data-attribute form

data-np-checkbox-group, no class needed.

Horizontal

np-checkbox-group-horizontal or data-orientation="horizontal".

Disabled

Native disabled on an input, or on a fieldset wrapping the group.

Parent checkbox

A few lines of oninput keep the parent in sync, including its indeterminate state.

Nested parent

Each group with a data-parent checkbox tracks the checkboxes inside it.
