Class form

class="np-toggle-group" with plain np-toggle items.

Data-attribute form

data-np-toggle-group with data-variant, data-size and data-spacing. Items use data-np-toggle.

Multiple and single

Multiple lets any item be on. Single keeps one item on at a time.

Variants

Default and outline.

Sizes

The group size applies to every item.

Spacing

Connected, default (2) and wide (4). Set --np-toggle-group-spacing for any step.

Vertical

Disabled

Set data-disabled on the group and disabled on each button.
