Class form

class="np-toggle"

Data-attribute form

data-np-toggle with data-variant and data-size, no classes.

Variants

Default and outline, each off and on.

Sizes

Small (1.75rem), default (2rem) and large (2.25rem) line up with Button and Input.

With text and icon

Fill icon

np-toggle-fill-icon or data-fill-icon fills a stroke icon while pressed.

Disabled

Invalid

aria-invalid="true" or data-invalid.
